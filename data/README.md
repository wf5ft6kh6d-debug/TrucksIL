# data/

Данные и схемы TrucksIL / TrucksIL data and schemas.

- `restrictions.schema.json` — JSON-схема записи об ограничении (высота, масса, запрет для грузовиков и т.п.) / JSON Schema for a road restriction record.

Все данные проходят верификацию по правилам [docs/DATA_VERIFICATION.md](../docs/DATA_VERIFICATION.md). Непроверенные данные нельзя считать безопасными. / All data follows the verification policy; unverified data must never be treated as safe.

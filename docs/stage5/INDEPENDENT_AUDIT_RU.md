## Сохраняющиеся блокеры и ограничения

1. Точный оригинал ранее переданного текста временных ограничений отсутствует. Подтверждение владельца — пользовательское свидетельство, не независимое официальное доказательство. Текст не восстанавливается из пересказа.
2. Официальная актуальность мостовых габаритов, единицы, дорожное направление и права на публикацию пользовательского XLSX не установлены. Историческая таблица не разрешает проезд сегодня.
3. Национальная чувствительность связности по node/way правилам не является полноценным применением времени и истории via-way; национальная stateful-маршрутизация остаётся BLOCKED, если явно не реализована и не проверена отдельно.
4. UNKNOWN-направления не добавляют направленные дуги. Включение в автомобильный исследовательский слой и TAGGED_ALLOWED не означают разрешения HGV или физической проходимости барьера.
5. Геометрическое пересечение не создаёт соединения; исходный граф, пилот, main и PR №1–3 менять запрещено. Полнота дорожных данных и безопасность маршрутов не подтверждены.

## Воспроизведение независимой части

```bash
python -m unittest discover -s tests -v
python scripts/stage5/independent_audit.py OUTPUT/research.jsonl --output OUTPUT/envelope-independent.json
python scripts/stage5/run_research.py GRAPH.sqlite SOURCE.osm.pbf OUTPUT --repeat
```

Полный интеграционный runner вызывает независимые full-row проверки и сохраняет `independent.json`. Сам envelope-проверяющий скрипт не заменяет полное source reconciliation. Изолированный PostgreSQL/PostGIS должен фактически выполнить сгенерированный SQL, проверки FK/GiST, отрицательные пробы, аудит, повторный импорт и rollback. Результат его исполнения и ссылки на итоговые CI обязательны в финальной приёмке.

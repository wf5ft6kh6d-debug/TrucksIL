## Реализованный контракт и границы

`scripts/stage5/bridges.py` читает OOXML стандартной библиотекой Python.
API: `normalize_workbook(path, retrieved_at=None)` возвращает `manifest`,
`records`, `summary`. Каждый record имеет SHA источника, XML member листа,
название листа, исходный номер строки, адрес/тип/значение/formula/style каждой
ячейки. Стабильный ID включает SHA, member и строку. Отсутствующие значения
не заменяются нулями. Формулы не вычисляются и cached value не используется
как измерение. Неизвестная раскладка сохраняет все строки в карантине.

Состояние всех 965 записей: **QUARANTINE**, интерпретация **UNKNOWN**,
`navigation_eligible=false`, VERIFIED=0. UNKNOWN — отдельная оценка
интерпретации, не второй взаимно исключающий статус тех же строк.
Распознана семантика заголовков и числовой синтаксис, а не действующее правило.
Геометрия null, направление UNKNOWN, совпадений с дорожным графом 0.
Номер дороги и километраж недостаточны, чтобы различить дорогу на сооружении
и дорогу под ним, направление/полосу, актуальный линейный километраж и OSM way.
Даже похожие идентификаторы не склеиваются.

## Воспроизведение

Только для имеющего право доступа к приватному оригиналу:

```bash
python -m scripts.stage5.bridges --input "$PRIVATE_BRIDGES_XLSX" --output-dir "$PRIVATE_OUTPUT_DIR"
python -m unittest tests.test_stage5_bridges -v
```

Выходы `manifest.json`, `records.jsonl`, `summary.json` — приватные. CLI не
публикует файл и не меняет исходник. Необходимо передавать приватный каталог
вне Git. Фактическое время получения можно явно передать `--retrieved-at`;
неизвестное время остаётся null. Повтор идентичного источника и параметров
даёт идентичные записи. CI использует только явно синтетические OOXML fixtures.

Локально выполнено 12/12 профильных тестов: идентичность оригинала/SHA,
строка/ячейки, единицы, различие опоры и габарита, даты, формулы, boolean,
неизвестная раскладка, пустые листы, запрет VERIFIED, numeric boundary,
детерминированный повтор. Общий набор и PostGIS исполняются интегратором.

## Блокеры действующих ограничений

Нужны подтверждённые происхождение и права, словарь единиц/полей, дата
измерения, действующий официальный источник для габарита/знака, геопривязка
дороги под сооружением, направление и независимая проверка. До этого
нельзя импортировать значения как эксплуатационные ограничения или выдавать
положительный вывод о возможности проезда.

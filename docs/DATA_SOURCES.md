# TrucksIL: инвентаризация источников данных (Этап 1)

_Дата: 2026-11-14. Статус: черновик исследования, не юридическое заключение._

Документ перечисляет кандидатов в источники данных об ограничениях для грузовиков (высота мостов, ограничения массы и осевой нагрузки, запреты движения, маршруты опасных грузов) и о дорожном графе Израиля. Он дополняет `docs/DATA_VERIFICATION.md`: ни один источник ниже пока не считается подтверждённым (`verified`) для решений о безопасности маршрута.

## Обозначения

- **[проверено]**: факт подтверждён веб-поиском 2026-11-14, ссылка приведена.
- **[общеизвестно]**: устоявшийся факт о проекте или организации, на момент написания не перепроверялся отдельным запросом.
- **[не проверено]**: предположение или пробел. Нужна проверка до использования.

## 2. Подробно по источникам

### 2.1 OpenStreetMap / Geofabrik

- **Данные:** полный дорожный граф Израиля; теги ограничений: `maxheight`, `maxweight`, `maxaxleload`, `maxlength`, `maxwidth`, `hgv=*` (включая `hgv:conditional` для временных запретов), `hazmat=*`. [общеизвестно, вики OSM: https://wiki.openstreetmap.org/wiki/Key:maxheight, https://wiki.openstreetmap.org/wiki/Key:hgv, https://wiki.openstreetmap.org/wiki/Key:hazmat]
- **Формат:** Geofabrik отдаёт регион «Israel and Palestine» (`.osm.pbf`): https://download.geofabrik.de/asia/israel-and-palestine.html [общеизвестно, URL не перепроверялся]. Также Overpass API, планет-файл.
- **Лицензия:** ODbL 1.0 (https://www.openstreetmap.org/copyright). Требуется атрибуция; производная база данных при публичном использовании должна распространяться под ODbL (share-alike). Отображённая карта («produced work») может иметь иную лицензию при соблюдении атрибуции.
- **Обновление:** OSM непрерывно; Geofabrik ежедневно.
- **Покрытие:** граф хороший; **покрытие тегов для грузовиков в Израиле не измерено [не проверено]**. Нужен анализ: доля мостов/туннелей с `maxheight`.
- **Статус:** неофициальный. По `DATA_VERIFICATION.md` сам по себе не может давать статус `verified`.
- **Доступ:** свободное скачивание; сообщество OSM Israel (вики: https://wiki.openstreetmap.org/wiki/Israel).
- **Риски:** неполнота и устаревание тегов; вандализм; share-alike ODbL при смешении с официальными данными; регион включает территории с особым правовым статусом (нужна политика отображения).

### 2.2 Нетивей Исраэль (Национальная дорожная компания)

- **Данные:** эксплуатирует большую часть междугородних дорог и мостов; на сайте есть стандарты проектирования мостов (глава 25, 2026) и альбом стандартных деталей в PDF/DWG [проверено: https://www.iroads.co.il/מידע-לספקים/הנחיות-תכנון-וביצוע/]. Есть центр управления движением и служба помощи *2120 [проверено: https://www.iroads.co.il/].
- **Реестр мостов / габаритов в открытом доступе: не найден [не проверено]**.
- **Формат/API, лицензия, частота:** [не проверено]. Публичного API не найдено.
- **Доступ:** официальный запрос через сайт; возможен запрос по Закону о свободе информации (חוק חופש המידע) [не проверено, применимость к гос. компании уточнить у юристов].
- **Риски:** данные могут считаться чувствительными (инфраструктура); не покрывает муниципальные дороги.

### 2.3 Министерство транспорта и безопасности дорожного движения (משרד התחבורה והבטיחות בדרכים)

- **Портал:** https://www.gov.il/he/departments/ministry_of_transport_and_road_safety [проверено]. ГИС-система «Хацав» (מערכת חצב): https://geo.mot.gov.il/ [проверено существование; содержание слоёв не проверено].
- **Правила:** нормы массы/габаритов и ограничения для тяжёлых ТС устанавливаются Правилами дорожного движения (תקנות התעבורה, 1961) и распоряжениями дорожных властей [общеизвестно; конкретные статьи не проверены]. Конкретные «запретные часы» для грузовиков на междугородних дорогах **не проверены**.
- **Политика:** СМИ сообщают о национальном плане перевести до 40% грузоперевозок на ночное время [проверено как публикация СМИ: https://www.akronjewishnews.com/news/nation_world/israel-to-shift-40-of-trucking-to-nighttime-to-ease-traffic/article_5267aa2d-0a60-5adb-8890-aae6d253772e.html]; первоисточник Минтранса не найден.
- **Разрешения на негабарит/опасные грузы:** выдаются (вероятно, отделом грузоперевозок и/или Министерством охраны окружающей среды для опасных веществ) [не проверено].
- **Формат/лицензия/частота:** [не проверено]; в основном PDF и тексты на иврите.
- **Риски:** нормативные тексты не машиночитаемы; изменения публикуются в Решумот (רשומות) без фида.

### 2.4 data.gov.il

- **Что есть:** национальный портал открытых данных, ~1200 наборов; Минтранс один из крупнейших публикаторов (ТС, ДТП, транспорт) [проверено: https://data.gov.il/datasets, https://data.gov.il/organizations/ministry_of_transport].
- **Наборов по высоте мостов, запретам для грузовиков, маршрутам опасных грузов не найдено [проверено поиском, отрицательный результат; нужна ручная проверка каталога]**.
- **Формат:** CSV и др.; API типа CKAN (`/api/3/action/...`) [общеизвестно, не проверено для текущей версии сайта].
- **Лицензия:** условия использования: https://data.gov.il/terms-of-use [ссылка проверена, текст не анализировался].
- **Полезно косвенно:** реестр ТС (масса, тип) для валидации профилей грузовика.

### 2.5 Полиция Израиля (משטרת ישראל), отдел дорожного движения

- **Данные:** оперативные перекрытия, ограничения на праздники/мероприятия [общеизвестно].
- **Формат/API/лицензия:** машиночитаемый фид не найден [не проверено].
- **Использование:** только как оповещение (`unverified`/временное), не как постоянная база.
- **Риски:** нет API; скрапинг соцсетей и сайта юридически и технически ненадёжен.

### 2.6 Муниципалитеты

- **Данные:** местные подзаконные акты (חוקי עזר) и знаки, ограничивающие въезд/часы для грузовиков в городах; в Тель-Авиве и Иерусалиме такие ограничения существуют [общеизвестно; конкретные зоны, часы и тоннаж **не проверены**].
- **Формат:** PDF актов, муниципальные ГИС-порталы (у Тель-Авива есть ГИС-портал и открытые данные [не проверено на наличие слоя ограничений для грузовиков]).
- **Доступ:** обращение в отдел транспорта каждого муниципалитета; ~250 местных органов.
- **Риски:** фрагментарность, разные форматы, нет единого реестра; временные знаки на месте важнее документа.

### 2.7 Центр картографии Израиля (המרכז למיפוי ישראל, MAPI) / GovMap

- **Данные:** национальные базовые карты, ортофото, ГИС-слои; GovMap: https://www.govmap.gov.il/ [проверено].
- **Лицензия:** есть отдельная услуга «заявка на лицензию на копирование и публикацию продукта MAPI» [проверено: https://www.gov.il/he/departments/survey_of_israel]. Значит, свободное использование по умолчанию не предполагается.
- **Наличие слоёв высот мостов/ограничений для грузовиков:** [не проверено].
- **Риски:** платность и условия лицензии; запрет скрапинга GovMap [не проверено].

### 2.8 Waze for Cities (Waze Partner Program)

- **Данные:** двусторонний обмен: партнёры получают инциденты/пробки, передают перекрытия (формат CIFS) [общеизвестно].
- **Условия:** программа ориентирована на госорганы, муниципалитеты, транспортные агентства; доступ частной коммерческой компании **не проверен**, вероятно ограничен. Общие условия Waze: https://support.google.com/waze/answer/12373727 [проверено].
- **Риски:** запрет на использование для конкурирующего навигационного продукта [не проверено]; нет данных о габаритах мостов.

## 3. Открытые вопросы для юристов

1. Совместимость ODbL (share-alike) с объединением OSM и официальных/лицензированных данных в одной базе; что считается «производной базой» в нашей архитектуре.
2. Условия data.gov.il: допускается ли коммерческое использование и переупаковка, требования к атрибуции.
3. Лицензия MAPI: стоимость, право на отображение в мобильном приложении, кеширование офлайн.
4. Можно ли получать данные Нетивей Исраэль и Минтранса по Закону о свободе информации; применим ли он к гос. компании; ограничения из-за безопасности инфраструктуры.
5. Ответственность за ошибочный маршрут (мост ниже указанного), дисклеймеры, страхование.
6. Правомерность скрапинга сайтов полиции, муниципалитетов, GovMap.
7. Waze for Cities: может ли частная компания участвовать; запреты на конкурирующее использование.
8. Политика отображения территорий за «зелёной чертой» (Иудея и Самария, Восточный Иерусалим) и чьи нормы там применимы.
9. Приватность: сбор пользовательских сообщений о препятствиях (Закон о защите частной жизни, 1981).

## 4. Рекомендуемые следующие шаги

1. **Измерить OSM:** скачать Geofabrik, посчитать долю мостов/туннелей (`bridge=yes`, `tunnel=yes` на путях под ними) с `maxheight`, и долю дорог с `hgv`/`maxweight`. Это даст реальную оценку покрытия.
2. **Ручной аудит data.gov.il и geo.mot.gov.il:** просмотреть все наборы/слои Минтранса, Нетивей Исраэль, муниципалитетов; зафиксировать в этом файле.
3. **Официальные запросы** (письменно, на иврите): Нетивей Исраэль, Минтранс (отдел грузоперевозок), MAPI, отделы транспорта Тель-Авива, Иерусалима, Хайфы. Спросить: наличие реестра мостов/габаритов, формат, лицензия, частота обновлений, контакт.
4. **Нормативная база:** собрать с юристом список актуальных норм (Правила ДД 1961, распоряжения о часах для грузовиков, правила перевозки опасных грузов) с номерами статей.
5. **Пилотный регион:** выбрать один город (например, Тель-Авив) и вручную верифицировать ограничения по `DATA_VERIFICATION.md`.
6. **Обновить схему** `data/restrictions.schema.json`: поле лицензии источника, чтобы отслеживать ODbL/иные условия на уровне записи.

## 6. Обновление от 14.11.2026: мосты и переписка с Минтрансом

Основано на материалах владельца проекта: выгрузка слоя «הפרדות מפלסיות כביש מסילה», спецификация слоя «גשרים» (XLSX/PDF) и переписка с руководителем GIS-системы «חצב» Минтранса (12.10–03.11.2026). Контактные данные сюда намеренно не включены.

### 6.1. Слой «הפרדות מפלסיות כביש מסילה» (geo.mot.gov.il)
- 500 записей (сервис отдаёт первые 500; полнота не подтверждена), ревизия Q2 2024.
- **Высот нет.** Годится только как справочник пересечений дорога/железная дорога, не для ограничений.
- Качество: 12 записей без дороги, километраж расходится с описанием, повторяющиеся значения, опечатки, 1 переезд (не мост), 3 неактивные линии.
- Статус в TrucksIL: `unverified`, только справочно.

### 6.2. Слой «גשרים» (спецификация v1)
- Поля высоты: `Gavrit_min` / `Gavrit_max` — **«по дорожному знаку»** (так в спецификации XLSX и в ответе Минтранса от 15.10.2026). Это именно то, что нужно водителю: юридически обязательное ограничение, которое он видит на знаке. Это не измеренный физический просвет; в данных храним `valueSource: posted_sign`.
- Единица не указана; пустые значения `-1`, для части записей `9999`.
- Есть полезные поля: `Placement` (полоса/направление), `Km`, `Trans_Use`, `Function`, `Source`, `D_Update` (ГГГГММ).
- **Слой ещё не опубликован** (ответ 15.10.2026): «в подготовке, будет опубликован в חצב и data.gov.il».
- Таблицы соответствия с историческим XLSX 2017 года нет; о правах на этот файл в Минтрансе не знают.

Правила загрузки (когда слой выйдет):
- `-1`, `9999`, пусто → «высота неизвестна», никогда не число.
- `valueSource: posted_sign`; значение показываем водителю как есть, без «поправок» (не путать с измеренным просветом).
- Запись `unverified`, пока не подтверждено, что знак на месте и значение совпадает (полевая проверка, фото, второй источник). Знаки меняют, поэтому важна дата `D_Update`.
- Единицу (м) подтвердить письменно до импорта.

### 6.3. Лицензия
- Ответы 15.10 и 20.10.2026: данные «חצב», включая этот слой, под **Creative Commons Attribution**; приведение значений к читаемому формату допустимо.
- **Не подтверждено:** версия лицензии (4.0?), официальная ссылка, точный текст атрибуции, распространяется ли лицензия именно на слой мостов. Также в ответе 15.10 есть фраза «не изменять информацию», которая противоречит обычному CC BY.
- 03.11.2026 отправлен повторный запрос с этими вопросами; ответа пока нет.
- До письменного ответа: сырые выгрузки Минтранса в репозиторий не кладём.

### 6.4. Дальнейшие шаги
1. Дождаться ответа на письмо от 03.11.2026; при отсутствии ответа — напоминание через 2 недели.
2. Подписаться на рассылку «חצב» и следить за публикацией слоя «גשרים» в data.gov.il.

4. Пока нет официальных высот — OSM `maxheight` только как кандидаты, с явным предупреждением в маршруте.

## 7. Нетивей Исраэль: что есть на сайте (обзор владельца, 21.11.2026)

- **Сеть:** 8 530 км дорог, 151 развязка, 1 615 «גשרים ומנהרות» (мосты и тоннели вместе), 3 034 перекрёстка, 107 045 знаков, 6 924 дорожных сооружения.

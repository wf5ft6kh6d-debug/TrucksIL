Аудитор не импортирует функции классификации пяти производителей. Проверка использует исходный PBF, SQL-сопоставление полных строк, исходные OSM идентификаторы, собственный NetworkX-граф, повторный расчёт геометрических предикатов и реестры каждого направления.

## Неизменность исходника

Исходный PBF SHA-256: `dff1ce395df33b8df901b85f7fd822bacd7a10985ceb2d893144251455646670`.

Исходная SQLite SHA-256 до и после локальных проверок: `fd4d29f0424f9d24b861c00b8ae0f954afb90c2d8af87cc9ff8f575a6aa1440a`.

Соединения аудитора открываются `mode=ro&immutable=1`. Непустой WAL блокирует такую проверку, чтобы не пропустить незафиксированные в основном файле страницы. Существовавший нулевой WAL не содержит данных. SQLite-файл при независимом восстановлении может иметь иной физический хеш; для него обязательны сравнение до/после и семантическое сопоставление с PBF, а не навязанный хеш конкретной локальной сборки.

Полное независимое чтение PBF подтвердило:

- координаты всех 4 414 569 узлов исследовательского графа;
- версии, timestamps, исходные теги и списки узлов всех 533 306 highway ways;
- версии, timestamps и исходные теги всех 26 188 кандидатов;
- версии, timestamps, теги и участников всех 14 463 отношений поворотов.

Это проверка происхождения OSM-данных, не независимое подтверждение физических дорожных характеристик.

## Воспроизведение

```sh
python scripts/stage4/independent_audit.py \
  --source /path/processed/graph.sqlite \
  --pbf /path/israel-and-palestine-261008.osm.pbf \
  --automotive /path/audit/automotive/automotive.sqlite \
  --audit-root /path/audit \
  --output /path/audit/independent-audit.json
python -m unittest discover -s tests -p test_stage4_independent.py -v
```

Запускать после завершения всех производителей. Хеши инфраструктурных реестров сверяются с завершённой сводкой. Три регрессионные проверки аудитора проверяют запрет записи в исходник, блокировку непустого WAL и обнаружение изменения `unknown` на `both` без доверия сводному отчёту производителя.

## Ограничения приёмки

Геометрическое совпадение, общий OSM node и направление из тега не доказывают физического соединения, разрешения грузового движения или актуальности дорожного приказа. Кандидаты и отношения сохраняют карантин; физические порталы, грузовая применимость и независимые официальные свидетельства не подтверждены.

Независимый повтор геометрических предикатов Shapely проверяет записи реестра. Полнота пространственного поиска между движками требует выполнения отдельного PostGIS SQL: он строит пространственный индекс и сравнивает весь набор пар и DE-9IM. Локальный Docker/PostgreSQL недоступен. Отдельное исполнение в GitHub Actions https://github.com/wf5ft6kh6d-debug/TrucksIL/actions/runs/38071577347 завершилось SUCCESS: PostGIS повторил полный поиск и сравнение IDs/DE-9IM, без расхождений. См. итоговый журнал и evidence/derived-ci-results.json.

Предварительные запуски аудитора обнаружили две неверные предпосылки самого аудитора: ожидание UNKNOWN вместо допустимого синтаксического разбора двух явно указанных единиц и ожидание дублирующихся tags в каждой компактной записи полного попарного реестра. Проверки исправлены: теперь явно проверяются единицы из исходной строки и исходные версии/геометрии независимо от наличия избыточных tags. Эти сбои не объявлены дефектами исходных дорог.

# Аудит геометрии национального исследовательского графа

Дата: 2026-10-10. Исходник ODbL-1.0, © OpenStreetMap contributors.
SHA-256 PBF: `dff1ce395df33b8df901b85f7fd822bacd7a10985ceb2d893144251455646670`.
География — экстракт Israel and Palestine, не юридическая граница Израиля.

## Метод и область проверки

Все 533 306 highway ways проверены Shapely на простоту. Для всех 1 662
несамопростых ways полные последовательности исходных node ID и координат
восстановлены из read-only SQLite. Второй алгоритм проверяет пары отрезков
целочисленными определителями на исходной точности OSM 10⁻⁷ градуса.
Он отличает собственное пересечение, касание и коллинеарное наложение;
обычное соседство отрезков и замыкание простого кольца не являются ошибкой.
Это проверка в плоскости WGS84: метрические допуски и геометрическое snapping
не применялись. Точность не используется для назначения дорожной доступности.

Полный перебор пар применяется только внутри 1 662 отмеченных ways, не ко всем
миллионам национальных сегментов. Междорожные пересечения мостов/тоннелей
проверяет отдельный инфраструктурный аудит. Прочие междорожные пересечения
не объявляются исчерпывающе проверенными этим отчётом.

## Две полностью совпадающие геометрии

- `1184440622` и `1184751220`;
- `1184440616` и `1184751224`.

Оба случая — `highway=service`, `service=parking_aisle`. Первый объект каждой
пары имеет `layer=2`, второй — `tunnel=building_passage`, без явного layer.
Совпадение исходных узлов и геометрии доказано, но равенство физических дорог
не доказано. Возможен конфликт моделирования уровней. Статус UNKNOWN;
следующий шаг — независимое свидетельство уровней, без слияния геометрий.
Детектор полных последовательностей учитывает обратное направление; он не
объявляет исчерпывающее топологическое равенство линий с различной плотностью
вершин или другим началом кольца.

## Вырожденная пара

`way=37161098`, `seq=8`: узлы **14250352838** и **431864510** различны, но оба
имеют координаты **35.1275978, 31.415053**. Это уточняет старый общий код причины
`same_id_or_coordinate`. Нулевое ребро уже исключено предыдущим обработчиком
и остаётся в QUARANTINE. Никакие координаты и узлы не заменены.

## Воспроизведение и артефакты

```sh
python scripts/stage4/geometry_audit.py /tmp/trucksil-national/processed/graph.sqlite /tmp/trucksil-stage4-audit/geometry
python -m unittest discover -s tests -p test_stage4_geometry.py -v
psql -X -v ON_ERROR_STOP=1 -d trucksil_stage4_test_audit -f /tmp/trucksil-stage4-audit/geometry/geometry-postgis.sql
```

Последняя команда требует доступной изолированной PostgreSQL/PostGIS через
Unix socket; SQL сам проверяет имя базы и отсутствие TCP, использует временные
таблицы и rollback. SQL сравнивает ST_IsSimple/ST_IsValid всех отмеченных ways
и ST_Equals всех геометрий повторных пар. Генерация SQL не считается его
исполнением; фактический результат PostGIS указывается в общем QA/CI.

Машиночитаемая сводка: `data/stage4/geometry-summary.json`.
Полные регистры генерируются в указанной выходной папке:
`nonsimple-ways.jsonl`, `repeated-pairs.jsonl`, `identical-way-geometries.json`,
`degenerate-pairs.json`, `geometry-postgis.sql`. Контрольные суммы — в сводке.
Крупные регистры сохраняются как артефакты проверки, не заменяют исходный PBF.

Добавлено **10 регрессионных тестов**; локально все 10 успешно исполнены.
Фикстуры синтетические и используются только в тестах, не в дорожной базе.

## Влияние на автомобильный граф

Аудит не меняет исследовательский или производный граф. Числа затронутых
автомобильных ways/сегментов записываются отдельным воспроизводимым пересечением
реестра геометрии с классификацией Automotive Graph Engineer. Ни UNKNOWN,
ни совпадение геометрии не позволяют автоматически удалить дорожный сегмент
или соединить разные уровни. Неопределённые физические соединения требуют
отдельного карантина маршрутного использования.

Фактически исполнено пересечение с текущей производной базой:

| Категория | INCLUDED ways / сегменты | EXCLUDED ways / сегменты | QUARANTINE ways / сегменты |
|---|---:|---:|---:|
| Несамопростые ways | 926 / 14 494 | 288 / 4 564 | 448 / 12 256 |
| Ways с повторными парами | 288 / 3 176 | 682 / 8 800 | 20 / 293 |

В таблице число сегментов **целых затронутых ways**, а не только сегментов
конкретной аномалии; строки могут пересекаться. INCLUDED — выбор автомобильной
классификации, не одобрение для навигации. Ни один из этих объектов не исправлен
и не признан безопасным этим аудитом. Воспроизведение с наложением:

```sh
python scripts/stage4/geometry_audit.py /tmp/trucksil-national/processed/graph.sqlite /tmp/trucksil-stage4-audit/geometry --automotive /tmp/trucksil-stage4-audit/automotive/automotive.sqlite
```

Полный геометрический проход до наложения занял **30,90 с** в данной среде.

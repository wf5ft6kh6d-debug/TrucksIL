## Разделение величин и конфликтов

Разрешённая полная масса, фактическая масса, осевая нагрузка, разрешение на негабарит, конструктивные размеры, размеры состава и физический просвет — разные основания. Поле полной массы справки для 406 требует уточнения вида массы по актуальному тексту. Историческая оговорка C1 требует отдельной проверки применимости к старым правам. Полный перечень исключений 407 нельзя восстановить по одному индексному фрагменту. Эти вопросы сохранены как неопределённость; содержательно доказанного основания переписывать справку как действующий нормативный документ не получено.

Ни 12 тонн, ни иной массовый порог не применён к неизвестной высоте. Общие нормы не добавлены ко всем рёбрам графа. Локальные условия Эйлата не распространены на город; частные условия оператора не опубликованы. Слои warning/block, маршрутизация и политика устаревания не изменены.

## Конечный метод и воспроизведение

Выполнены ограниченные поисковые проходы по трём группам (знаки/исключения, лицензии, габариты), затем целевые открытия обнаруженных официальных документов. Первый поисковый движок дал нерелевантные ответы; второй дал точные URL. Повторные HTTP 403 не обходились, бесконечного поиска не было. Поля `source_status`, `visual_pdf_verified`, `locator`, `web_reference` показывают, что действительно прочитано. Сведения из индекса не маркируются визуально проверенными.

Проверить `data/stage8/reviews-vehicle.json` по общей `review.schema.json`, ссылки source ID по `sources-vehicle.json`; сверить 19 уникальных ID и запрет operational_change/navigation_eligible. Полная интеграционная проверка и аудит выполняются отдельно владельцем интеграции. Производственный код не менялся; отдельные тесты, повторяющие статические константы, не добавлялись. PostgreSQL и CI на уровне этого направления не запускались — их итог нельзя заявлять до общего прогона.

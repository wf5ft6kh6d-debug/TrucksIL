# Этап 8: добавочный реестр проверок

База: 4f2fd1214e2c8b5e5d12bc818c505398b1fd171e (этап 7).
Существующие дорожные записи, 965 нормализованных исторических строк,
маршрутизатор и пилот Хайфы не пересоздаются. Новые review-записи являются
приложением к проверке утверждений, а не новыми локальными запретами.

## Общий контракт

`stage8.review.v1` хранит ID проверки, subject_id проверяемого утверждения,
тип NORM/LOCAL_RESTRICTION/CLAIM/GAP, собственный вывод проверяющего и ссылки
на отдельный реестр источников. Достоверность, интерпретация, актуальность,
геопривязка и права — независимые поля. Например SUPPORTED для толкования
нормы не переводит локальный дорожный факт в VERIFIED. UNKNOWN сопровождается
причинами. VERIFIED в данном контракте запрещён; при появлении достаточных
доказательств потребуется отдельно проверенный путь индивидуального аудита.

`navigation_eligible=false` и `operational_change=false` обязательны. Никакого
подключения warning/block к рабочей маршрутизации не добавлено. Значение
BOUND не означает национальную полноту. NORM не становится LOCAL_RESTRICTION
через результат теста или упоминание номера дороги.

Входы: `sources-*.json` с `sources`, совместимые с метаданными этапа 7;
`reviews-*.json` с `reviews`. Дубликаты ID и неизвестные ссылки отвергаются.
Публичный режим допускает только `rights_status=PUBLIC_METADATA_ONLY`.
Эта отметка является результатом отдельной проверки состава публикации, а не
автоматическим разрешением копировать документ. Частные цитаты, исходная
справка и её производные остаются вне Git и публичного CI. `--private` явно
выбирает локальный закрытый режим. Публичный CLI по умолчанию закрытый режим
не включает.

## Воспроизведение

```
python -m unittest discover -s tests -v
python scripts/compare_schema_engine.py
python scripts/stage6/contract.py
python scripts/stage8/run_review.py data/stage8 /tmp/trucksil-stage8-review --repeat
```

Выходной каталог не должен существовать. Создаются `reviews.jsonl`,
`reviews.csv`, `sources.json`, `summary.json`, `manifest.json` и SQL.
Manifest фиксирует SHA-256 и размер каждого результата, кроме самого manifest;
summary фиксирует хеши входов. Повтор сравнивает все выходы побайтно, исходники
хешируются до и после обработки. Пустой реестр не заменяется синтетикой.
Тестовые данные находятся только в тестах и явно названы synthetic.

## База данных и CI

Использован прежний транзакционный storage этапа 6 и неизменяемый реестр
источников этапа 7. Полные review и метаданные источников сохраняются в raw.
Новый SQL-trigger проверяет пять измерений статуса, отсутствие VERIFIED,
операционных изменений и навигационного допуска, причины неопределённости,
ссылки и неизменность источников. SQL ограничен Unix socket и изолированной
БД `trucksil_stage8_test_*`. Полная эквивалентность Python JSON Schema и SQL
не заявляется: Python проверяет полную схему, SQL — критические ограничения.

Обязательный CI: полный набор прежних 404 тестов плюс новые тесты, прежние
54+38 сравнений схем, точное повторение stage7 и stage8 публичных результатов,
действительный PostGIS, повторный импорт, аудит и rollback. Унаследованный
CI сохраняет пилот Хайфы и старые отрицательные проверки. PBF не перестраивается:
исходный граф и маршрутизатор не изменены. Созданный SQL не считается
выполненным SQL. Окончательные SHA, логи, версии и исходы фиксируются итоговой
приёмкой после завершения обоих CI.

## Изменения относительно этапа 7

| Область | Было | Добавлено | Основание |
|---|---|---|---|
| Реестр дорог | stage7.restriction.v1 | Не изменён | Нет новых доказанных локальных запретов |

## Проект решений для отдельного утверждения — не внедрён

| Ситуация | Предложение |
|---|---|
| UNKNOWN, просроченная или конфликтующая критичная запись | Показывать неопределённость без автоматического разрешения |
| Подтверждённая общая норма, неизвестная локальная применимость | Сохранить как норму; не создавать запрет участка |
| Индивидуально доказанный локальный факт | Обсудить перевод в VERIFIED отдельно от операционной политики |
| Нужен платный документ, обращение или передача частных данных | Сначала получить отдельное согласие |

Произвольные запасы высоты, универсальные 12 тонн для неизвестного габарита,
обязательное обследование всех мостов и гарантии безопасности не вводятся.

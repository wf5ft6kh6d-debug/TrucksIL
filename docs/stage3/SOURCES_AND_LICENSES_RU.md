# Этап 3 — источники и права, 10 октября 2026

Машиночитаемый реестр: `data/stage3/source-registry.json` (12 записей).
Для каждой записи указаны владелец, URL, способ получения, формат, охват,
лицензия/решение, даты и ограничения. `null` означает неизвестную дату или
неподтверждённую лицензию; дата чтения не подставляется вместо даты публикации.

## Разрешённый пилот

[OSM](https://www.openstreetmap.org/copyright) публикуется по
[ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Подтверждены возможность
копирования/переработки с атрибуцией и условиями распространения производной БД.
OSM хранится отдельно от государственных материалов; уведомление и лицензия
в `data/stage3/LICENSE.md`. Это не подтверждение содержания дорожных тегов.

Использован [Overpass](https://dev.overpass-api.de/overpass-doc/en/preface/commons.html):
один небольшой запрос, без повторов, ротации адресов и обхода ответов сервера.
Редактирующий OSM API и тайлы не использовались. Overpass не является будущим
операционным backend TrucksIL. Для больших объёмов есть
[Geofabrik](https://download.geofabrik.de/asia/israel-and-palestine.html):
PBF/SHP/GeoPackage, но этот региональный файл не скачан; его граница не является
утверждённой зоной навигации. Лицензия OSM не превращает его в официальный источник.

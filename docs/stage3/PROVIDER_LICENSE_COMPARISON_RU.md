## Подтверждённые открытые права

ODbL подтверждена для **конкретного** CleanAir GeoJSON Хайфы от27.04.2025. Это геометрия зоны, не актуальные условия HGV. Не распространять её на муниципальный GIS/приказы. Существующий OSM-срез остаётся под прежней ODbL; новый коммерческий материал в него не добавлялся. Никаких новых лицензионных соглашений не принято.

PTV GLA2026-03-30 §4.3.1/4.3.6 ограничивает базу/derivatives без отдельного соглашения; §4.3.7 требует проверки сочетания с другими geodata. Trimble evaluation — внутреннее тестирование, не коммерческое standalone extraction. Mapbox ProductTerms2026-07-21 §2.10.1 ограничивает хранение/экспорт Navigation results; §1.5/1.6 — derived/extraction. Govmap требует письменных прав коммерческого использования/сбора. Эти выводы не исключают согласования отдельного договора.

## Что должно быть явно разрешено до приёмки

- Конкретные территория, продукт, версия, поля и цель коммерческого использования.
- API и скачивание; постоянное хранение, резервные копии, нормализация/PostGIS и обновления.
- Сопоставление с OSM, условия раздельного хранения, атрибуция и возможные обязательства ODbL.
- Производная база, отображение в чужой карте, выдача клиентам/API, распространение.
- Период лицензии, стоимость/минимальный объём, обновление, удаление при прекращении, исправление ошибок.
- Происхождение, наблюдение/вступление в силу, полнота, независимое свидетельство, различие unknown и no restriction.

Официальные URL и source IDs для каждой строки сохранены в TRUCK_DATA_PROVIDERS_RU.md и JSON. Стоимость приложения/запроса не является стоимостью лицензии дорожного контента. Платных запросов, покупок и импортов нет.

## Причины несвязности и неизвестных направлений

1995 узлов /2168 сегментов /5 компонент /100 конечных узлов сохранены.
Анализ использует уже сохранённые полные ways; точки за bbox — только контекст.

- **36/100** узлов степени 1 имеют соседний допустимый дорожный сегмент raw,
  который обрезан по bbox: доказуемое влияние границы.
- **21/100** имеют смежные исходные ways исключённых классов (например, footway
  или steps), но не дорожное продолжение за bbox. Это влияние фильтра/модели,
  **не доказательство существования проезда для грузовика**.
- **43/100** не имеют ни такого граничного, ни отфильтрованного продолжения в
  доступном raw. Это endpoints с неустановленной реальной причиной: нельзя
  объявить их ни ошибками OSM, ни подтверждёнными тупиками.
- Компоненты размеров 1976 и 2 объединены через пути за bbox в имеющемся raw.
  Их разделение — эффект обрезки. Компоненты 9, 5 и 3 остаются отдельными
  даже в имеющемся полном raw, однако у каждой есть граничные выходы.
  Ограниченный исходный запрос не доказывает реальную изоляцию этих дорог.
- Все **575 unknown-сегментов относятся к 158 ways без тега oneway**.
  Ни один из них не вызван conditional/неподдерживаемым значением в этом срезе.
  Присвоение both по умолчанию не выполняется. Общие OSM-defaults не являются
  достаточным свидетельством для принятой политики достоверности TrucksIL.

NetworkX независимо строит граф прямо из raw и сверяет распределение 100
конечных узлов, 5/4 компоненты clipped/context, направления четырёх relations
и число отсутствующих oneway. Это дополняет прежний независимый графовый аудит.

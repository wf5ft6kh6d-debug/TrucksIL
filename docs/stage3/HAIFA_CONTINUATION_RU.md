## Диагностика графа

Исходный bbox [34.990,32.811,35.004,32.821] сохранён: 1995 узлов, 2168 сегментов.
Географическое покрытие не расширено. Связность основана на совпадении OSM node
ID; пересечение линий или одинаковые координаты сами по себе не создают связь.
Теги bridge/tunnel/layer сохраняются, инженерная проверка развязок не выполнена.

- 5 слабых компонент: 1976, 9, 5, 3, 2 узла; 100 узлов степени 1.
  Обрезка по bbox и фильтр типов дорог могут разрывать граф; это не диагноз
  ошибки OSM и не основание искусственно соединять компоненты.
- 1560 сегментов forward, 33 both, 575 unknown. По явным направлениям 1626 дуг;
  1564 сильных компоненты, крупнейшая 281 узел. Unknown не становится both.
  Компоненты не учитывают исполнение поворотов и не являются маршрутизатором.
- 113 relations остаются quarantine: 42 структурно согласованы, 48 имеют
  неизвестное направление, 19 вне обрезанного графа, 2 неподдерживаемой структуры
  (12303230, 13395546), 2 кандидата на конфликт направления (10115408, 10115411).
  Последние требуют ручной проверки геометрии/направления/смысла манёвра;
  это не установленная ошибка OSM. Противоречивых целевых only/no наборов — 0
  в ограниченном поддерживаемом анализе, не доказательство полной согласованности.
- Условия, исключения hgv, via-way/сложные отношения не упрощаются;
  грузовая применимость остаётся unknown. Ни одно отношение не опубликовано
  как навигационное ограничение. Даты OSM-редактирования не даты наблюдения знака.

## Воспроизведение и границы проверки

```sh
python -m unittest discover -s tests -v
python scripts/compare_schema_engine.py
python scripts/stage3/build_pilot.py --output evidence/pilot
python scripts/stage3/audit_graph.py evidence/pilot/graph-audit.json
python scripts/stage3/compare_graph_engine.py evidence/pilot/normalized.json evidence/pilot/graph-audit.json
python scripts/stage3/compare_geometry_engine.py evidence/pilot/normalized.json
```

NetworkX 3.4.2 независимо сравнивает полные множества слабых/сильных компонент,
степени и дуги. JSON Schema corpus и геометрии проверяются jsonschema 4.23.0.
`graph-audit.sql` строится из прежнего защищённого replay исходного графа,
добавляет независимые SQL-агрегаты степени/направлений и делает ROLLBACK.
В CI только изолированный PostGIS без сети, Unix socket и disposable database;
старые миграции, checksum gates, триггеры и SQL-тесты сохраняются.
Фактические результаты CI фиксируются в WORK_LOG после исполнения.

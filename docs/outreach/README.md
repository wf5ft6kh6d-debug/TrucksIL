# Outreach: запросы данных о дорожных работах и ограничениях

## Назначение
Черновики писем операторам дорог с запросом информации и **условий лицензии** на данные о плановых/текущих работах, перекрытиях, инцидентах, габаритах мостов и ограничениях для грузовиков (см. `docs/research/NAVIGATORS.md`, п. 8; `docs/DATA_SOURCES.md`). Открытого API Нетивей Исраэль и Аялон не найдено — нужен прямой запрос.

| Файл | Адресат | Язык |
|---|---|---|

Ничего не отправлено. Письма отправляет владелец лично, подставив своё имя и email вместо `[שם]` / `[אימייל]`.

## Где найти официальные контакты (проверено 2026-11-21)
Адреса email не выдумываем. Если адрес не указан на официальной странице — «найти на сайте».

- **Нетивей Исраэль:** форма обращений граждан — https://www.iroads.co.il/support-form/ ; телефон *2120 (указан на сайте). Email — найти на сайте (https://www.iroads.co.il/). Сторонний сайт приводит адрес обращений, но он не официальный — перед отправкой сверить на iroads.co.il.
- **Нетивей Аялон:** форма «צרו קשר» — https://www.ayalonhw.co.il/contact-us/ ; телефон *8541 (по выдаче поиска). Для запроса по Закону о свободе информации — ссылка с той же страницы: https://www.ayalonhw.co.il/company-activity/freedom-of-information/ . Email — найти на сайте.
- **Waze for Cities:** https://www.waze.com/partners/wazeforcities ; инструменты обмена данными: https://support.google.com/waze/partners/answer/10618047 . Заявка — через форму на сайте программы (найти на сайте).

Вариант: если формальный канал не ответит, у обеих компаний есть процедура по Закону о свободе информации (חוק חופש המידע) — может быть платной, поэтому только с письменного согласия владельца.

## Что приложить
- 1–2 предложения о проекте и ссылку на публичный репозиторий (если опубликован).
- Ссылку на лицензию кода (Apache-2.0, ADR-0010) и описание safety-first политики (ADR-0002): внешние данные — только предупреждение/исключение, не основание «проехать можно».
- Пример желаемого формата атрибуции. Никаких персональных данных сверх контакта владельца.

## Сроки follow-up
- Через 14 дней без ответа — короткое вежливое напоминание тем же каналом.
- Через 30 дней — второй канал (телефон / другая форма) или запрос по свободе информации (с согласия владельца).
- Ответы сохранять (PDF/скрин) вне репозитория; в репо — только вывод и ссылку на ADR.

## Важно (ADR-0007, ADR-0002)
Никакие данные этих источников **не используются и не коммитятся** до письменного подтверждения лицензии правообладателем. После получения — новый ADR с текстом атрибуции. Скрейпинг сайтов и приложений (включая Waze) запрещён.

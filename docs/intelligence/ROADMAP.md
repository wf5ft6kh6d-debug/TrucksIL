# Дорожная карта
Предварительный ориентир 12–20 недель для ограниченного пилота при наличии команды, доступа и утверждённых требований; не обязательство по срокам.

| Недели | Этап | Результат |
|---|---|---|
| 1–2 | Аудит и архитектура | Карта интеграции, ADR, границы безопасности |
| 2–5 | База доказательств | Схема, версии, карантин, аудит |
| 4–8 | Research | Реестр источников, адаптеры, планировщик, повторная проверка |
| 6–10 | Verification | Проверка привязки, конфликтов, ручное утверждение |
| 8–13 | Community | Очередь запросов, безопасный UX, антифрод |
| 11–16 | Traffic/Route/Voice | Теневой режим, альтернативы через ядро, TTL |
| 16–20 | Пилот Хайфа | Независимые испытания, решение о допуске |

Расширение после пилота: север, центр, Иерусалим, Ашдод, юг, Эйлат. Приоритет по грузовым коридорам, рискам и пробелам данных, а не по фиксированному календарю. Исследовательский агент может работать параллельно с ядром, но только в изолированном контуре после согласования.

Контрольные ворота: G0 аудит и разрешение владельца; G1 изолированный сбор с лицензиями и бюджетом; G2 проверка доказательств без публикации; G3 теневой режим; G4 независимая оценка и отдельное решение о полевом пилоте. Календарь не заменяет прохождение ворот.

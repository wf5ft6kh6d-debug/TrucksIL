## Обязательные критерии

1. Для каждого артефакта отдельно отмечаются упоминание в отчёте, доступность байтов и проверка содержимого. Проверка включает SHA-256, размер, число записей, поля и связь с принятым источником. Недоступность не означает отсутствия. Повторный импорт 965 исторических строк не выполняется.
2. Каждая запись имеет проверяемую цепочку источник → точный фрагмент/пункт → исходное утверждение → интерпретация. Пользовательское подтверждение остаётся пользовательским свидетельством. Главная страница, поисковая выдержка и недатированный пересказ не подтверждают конкретный действующий запрет.
3. Для VERIFIED необходимо документированное подтверждение авторитетности и актуальности, точной применимости, участка/объекта, направления, категории ТС, значения/единиц и вида массы либо габарита, сроков, исключений и отсутствия неразрешённого противоречия. Неприменимые поля отмечаются с объяснением. Наличие каждой требуемой характеристики проверяется по источнику, а не только по заполненности полей.
4. Высота сооружения, физический просвет и значение знака различаются. Историческая строка не становится текущим свидетельством; число реально перепроверенных объектов считается отдельно от технически сверенных 965 строк.
5. Общие нормы транспортного средства отделены от локального запрета. UNKNOWN с причиной не превращается в разрешение; предлагаемая warning/block-матрица не изменяет поведение маршрутизации без отдельного утверждения.
6. Геопривязка сохраняет неоднозначность дороги, направления и полосы. Не создаются соединения по геометрическому пересечению. Граница PBF не объявляется юридической границей страны. Исследование региональных источников не равно полноте дорожных данных.
7. Публичная доступность материала не доказывает право перепубликации. Частные оригиналы и закрытые производные не попадают в Git/CI. Реальные факты, источники, исторические записи и синтетические fixtures считаются отдельно.
8. Все 355 старых тестов и защищённые исходники сохраняются. PostgreSQL/PostGIS, повторный импорт, аудит, rollback, точный replay и CI выполняются на конечном SHA. Статический SQL и успешные Python-тесты не подменяют фактическую БД.

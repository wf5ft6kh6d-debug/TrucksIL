# Этап 7: интеграция доказательств

База d7ded75d7b040ac3d9a3a7ce16113a2e7cd1b328. 355 прежних тестов и
код маршрутизации не изменены. Новый конверт stage7.restriction.v1 хранит
дорожное утверждение отдельно от source_status, evidence_status и
interpretation_status. UNKNOWN имеет явную причину. GENERAL_VEHICLE_NORM
не равен LOCAL и не образует запрет участка. Геометрия nullable; отсутствие
привязки не означает разрешение. navigation_eligible всегда false.

Источники находятся в sources-*.json, записи и блокеры — records-*.json.
Идентификаторы и ссылки проверяются; дублирующиеся ID отклоняются. Число
источников-ID и число уникальных URL выводятся отдельно. Неизвестные единицы,
направление, полоса, даты сохраняются null. Сведения о правах остаются в
метаданных; наличие ссылки не разрешает переиздание документа. В публичный
runner включаются только предварительно проверенные файлы data/stage7.
Приватные 965 исторических строк не импортируются и не публикуются.

Кандидат VERIFIED требует встроенной документированной проверки и внешнего
реестра индивидуального аудита с SHA-256 точной записи. В этом этапе ни одна
запись не переведена в VERIFIED. SQL-генератор вообще запрещает такой перевод:
его включение потребует отдельного явно проверенного пути. Самоподписанная
запись, успешные тесты или имя проверяющего не являются доказательством факта.

## Воспроизведение

```
python -m unittest discover -s tests -v
python scripts/compare_schema_engine.py
python scripts/stage6/contract.py
python scripts/stage7/run_research.py data/stage7 /tmp/trucksil-stage7-result --repeat
```

Выходной каталог должен отсутствовать. Runner создаёт JSONL и CSV записей,
JSON источников/блокеров, матрицу покрытия CSV/JSON, реестр геопривязок,
наблюдение графа, SQL, summary и manifest с SHA-256/размерами. Все файлы
повторного запуска сравниваются побайтно. Исходные реестры хешируются до и
после. `--graph PATH` допускает только чтение существующего графа через
coverage.py; без него наблюдение геопривязки UNKNOWN, не фиктивный PASS.
Заявление о точном повторе относится к одинаковым входам и параметрам.

Приватное расширение воспроизводится тем же runner с отдельным каталогом
вне Git: источники плюс явно разрешённые локально records-*.json. Его вывод
также остаётся вне Git/CI. Это не повторный импорт XLSX. Распаковка частного
архива и проверки исторических строк принадлежат соответствующим агентам.

## PostgreSQL / PostGIS

Повторно использован проверенный transactional storage конверт этапа 6.
Полная запись этапа 7 и все связанные метаданные сохраняются lossless в raw.
Внешний source_type=user_report обозначает производное утверждение
исследовательского обработчика; реальная классификация каждого первоисточника
остаётся в raw.sources, и официальный статус не назначается автоматически.
Новый SQL-trigger проверяет критические поля этапа 7, отсутствие допуска к
навигации/VERIFIED, статус интерпретации, геометрию, причины UNKNOWN, ссылки
и неизменность метаданных реестра источников. Python дополнительно валидирует
полную JSON Schema. Полная эквивалентность Python и SQL не заявляется.

SQL допускает только Unix socket и БД trucksil_stage7_test_*. Контейнер
PostgreSQL/PostGIS закреплён digest этапа 6, без сети и опубликованных портов.
Временная схема создаётся в транзакции; проверяются полный payload, GiST,
повтор без дубликатов/audit, old/new audit, отрицательные попытки изменения
статуса, допуска, provenance и журнала; после ROLLBACK схема отсутствует.
Фактический успех — STAGE7_POSTGIS_PASS в выполненном psql, не наличие SQL.

CI stage7-evidence выполняет все старые/новые тесты, 54 прежних и 38 stage6
сравнений схем, точное повторение публичных реестров и настоящий PostGIS.
Унаследованный workflow дополнительно повторяет Хайфу, миграции, историю и
отрицательные rollback/checksum сценарии. Полный неизменённый национальный
PBF повторно не строится: маршрутизатор/граф не изменены, этап 6 проверен.
Национальность этапа 7 относится к конечному исследованию региональных
источников, не доказанной полноте сети/запретов.

## Проект решения warning/block — НЕ ВНЕДРЁН

| Доказательность и интерпретация | Предложение для будущего утверждения |
|---|---|
| UNKNOWN/QUARANTINE или конфликт | Сообщать неопределённость; не выводить разрешение |
| VERIFIED, SUPPORTED, точная применимость | Рассмотреть block лишь после отдельного продуктового решения |
| VERIFIED, но неизвестная применимость/время | Сообщать неопределённость; не делать автоматический block/allow |
| Нет найденной записи | Не считать дорогу свободной от ограничений |

Матрица только документ. Не добавлены warning/block вызовы, UI или изменения
маршрутных решений. Техническая приёмка, достоверность дорожных фактов и
пригодность для навигации оцениваются раздельно в итоговом аудите.

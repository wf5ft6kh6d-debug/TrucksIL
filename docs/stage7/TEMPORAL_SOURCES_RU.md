# Этап 7 — временные ограничения и официальные источники

Проверка 12 октября 2026 года. Конечный план исследования выполнен с блокерами. Это исследование по всем шести региональным группам, не перепись всех муниципалитетов и не подтверждение полноты дорожных данных. Новых извлечённых действующих временных ограничений: **0**. Это не означает отсутствия запретов.

## Что реально доступно и проверено

Существующий приватный `stage6-private/claims/registry.json` прочитан и проверен валидатором этапа 6. Все 11 исходных утверждений, Unicode-срезы, первоначальная дата, свидетельство владельца, источник и отсутствующие поля сохранены без изменений. Для каждого создана отдельная запись проверки этапа 7. Повторного импорта исторических мостовых строк и изменения исходного текста нет.

Приватные результаты находятся в `stage7-private/temporal/`: `reviews.json`, `temporal-evidence-gaps.json`, `temporal-evidence-gaps.jsonl`, `summary.json`, `manifest.json`. Последний содержит размеры и SHA-256. Эти файлы исключены из Git и публичного CI. Реестр содержит 11 QUARANTINE, 0 VERIFIED, 0 UNKNOWN по статусу свидетельства; интерпретация UNKNOWN у всех 11. Во всех 11 по-прежнему неизвестны дни и даты действия, в 8 — направление, в 9 — масса. Наследование массы из заголовка не выполняется.

Публичные файлы:

- `data/stage7/sources-temporal.json`: 16 источников/поисковых адресатов и 20 фактических попыток поиска с запросом, движком, проходом, датой и результатом.
- `data/stage7/records-temporal.json`: пустой массив новых правил и 7 региональных/национальный блокер.

16 записей источников нельзя называть 16 прочитанными документами: 10 — только домены поисковых адресатов, 2 — прочитанные страницы, 3 — HTTP 403, 1 — географическая блокировка. Одна из 20 попыток имеет `query_pass=0`: ошибочный оператор `site.gov.il`, нерелевантная выдача, исключена из охвата. Остальные 19 — поисковые попытки; результаты не равнозначны найденным ограничениям.

2. `T-MOT-ROAD1-AUDIT-2017`: https://www.gov.il/BlobFolder/generalpage/infrastructure_and_engineering_content_bank_2017_5/he/bakara_rashuyot_timrur_2017_derech_eretz.pdf — исторический аудит знаков дороги 1, HTTP 403. Номер страницы не выдуман; знаки 2017 года не удостоверяют состояние 2026 года.
3. `T-MOT-QUARRY-REPORT`: https://www.gov.il/BlobFolder/reports/import_materials/he/Import_of_quarrying_materials_to_Israel.pdf — поисковый указатель на печатную страницу 33 с историческим режимом дороги 232; полный документ HTTP 403. Видимое различие часов — неразрешённый указатель для проверки, а не установленное противоречие и не замена пользовательского текста.
4. `T-KNESSET-2008`: https://fs.knesset.gov.il/globaldocs/MMM/ecc28d55-f7f7-e411-80c8-00155d010977/2_ecc28d55-f7f7-e411-80c8-00155d010977_11_10096.pdf — перенаправление на `maintenance-page-geo`. Этап 6 сообщил чтение исторических страниц 3–4; этап 7 не заявляет повторного чтения PDF. Отмена прежнего пилота не доказывает отсутствие более позднего запрета.
5. `T-TLV-PILOT`: https://www.tel-aviv.gov.il/Residents/Transportation/Pages/distributionvehicles.aspx — раздел пилота погрузки/разгрузки сообщает завершение пилота 2020 года в начале 2021 года. Не преобразован в действующее маршрутное правило.
6. `T-TLV-TERMS`: https://www.tel-aviv.gov.il/About/Pages/TermsofService.aspx — раздел использования сайта ограничивает повторное использование содержания и создание базы. Сохранены библиографический адрес и результат проверки, без снимка страницы, перепечатки или извлечённой базы городских правил. Для массового импорта необходима проверка разрешённого основания/лицензии.

Полные страницы, фотографии и закрытые данные не опубликованы. Для недоступных документов права UNKNOWN. Указатель на существующий официальный адрес не означает успешное чтение его содержания. Материалы тендеров, стратегия логистики, парковка и режим движения разделяются. Общая формулировка оператора тоннеля, рассмотренная в этапе 6, не доказывает ночное разрешение и не распространяется автоматически на все городские дороги.

## Воспроизведение

```bash
python -m unittest discover -s tests -p test_stage7_temporal_gaps.py -v
python scripts/stage7/temporal_gaps.py \
  PRIVATE_STAGE6/claims/registry.json PRIVATE_STAGE7/temporal/reviews.json \
  data/stage7/sources-temporal.json PRIVATE_STAGE7/temporal/reproduced.json \
  --checked-at 2026-10-12
```

12 синтетических тестов: полнота покрытия исходных ID, неизменность оригинала, проверка связей источников, отказ при повреждении происхождения, запрет присвоения VERIFIED через обзор, отсутствие разрешения при неудачном поиске, закрытый агрегированный публичный экспорт. Реальные пользовательские утверждения не встроены в tests. Повтор результата с теми же входами побайтово детерминирован; успешные тесты не доказывают дорожный факт.

Обращений от имени пользователя не отправлено. Остальные территории остаются в реестре пробелов; отсутствие найденного документа не объявляется свободным проездом.

# Этап 7: сооружения и габариты

Продолжены 965 принятых строк этапа 5 и 965 записей пробелов этапа 6. Все семь
доступных входных файлов прочитаны; входные SHA-256 этапа 5 сверены с manifest
этапа 6, ID/лист/XML member/строка сверены, прежние пробелы полностью сравнены
с воспроизводимым результатом принятого алгоритма. Создание в старом отчёте,
доступность файла и фактическая проверка содержимого различаются в manifest.
XLSX повторно не импортирован; исходные файлы не изменены.

Новый частный реестр для каждой строки фиксирует подтверждённую цепочку
документов, открытые ворота доказательств, наличие исторических наблюдений,
приоритет и неизвестность единиц, направления, полосы и даты измерения.
Подтверждённая цепочка документов не является подтверждённым дорожным фактом.
965 QUARANTINE; интерпретация UNKNOWN для всех 965; VERIFIED 0; индивидуальные
внешние проверки исторических объектов 0; новых подтверждённых совпадений 0.
Прежние очереди 327/8/430/136/64 сохранены без численного сравнения неизвестных
единиц и без объявления высоты опоры габаритом проезда.

## Конечный план исследования и фактический результат

Не более двух проходов поиска на целевую группу; после получения доступных
страниц и условий использования поиск остановлен. Проверены следующие группы:

| Группа | Фактически прочитано | Результат |
|---|---|---|
| Национальное руководство по высотным препятствиям 2026 | Поисковое обнаружение; полный PDF недоступен | Норматив не извлечён; тем более не подтверждает конкретные строки |
| Netivei Israel / Хараль | Страница тендера недоступна, строительный первоисточник Electra прочитан | Идентичность проекта; текущий разрешённый габарит не установлен |
| Хайфа / тоннели Кармель | Страница оператора, государственная проектная страница и условия обоих сайтов | Частное свидетельство ограничения и отдельное описание сооружения; эти значения семантически различны |
| Тель-Авив / муниципальный GIS | Схема слоя 550 мостов и тоннелей | Полей габарита нет; дата загрузки не дата измерения; объекты не скачивались |
| Оператор дороги 6 | Главная страница и два поисковых прохода | Пригодный документ о габаритах не найден; главная страница не доказательство отсутствия запрета |
| Южный регион / Беэр-Шева | Два прохода поиска, муниципальный вход недоступен | Проверка территории остаётся неполной; актуальный документ не получен |

10 записей библиографии и условий доступа находятся в
`data/stage7/sources-structures.json`; точные URL и локаторы сохранены там.
Национальный охват плана не означает сплошную проверку национального перечня.
Независимый национальный эталон с известной полнотой и разрешённым использованием
не получен; полнота UNKNOWN. Локальная проверка трёх выбранных групп сооружений
(Кармель, Хараль, муниципальная инвентаризация Тель-Авива) не распространяется
на все мосты страны.

Условия оператора Кармель, раздел 7, ограничивают использование частными
целями; подтверждённых прав публикации извлечённой базы нет. Извлечённая
запись и структурное наблюдение хранятся **только в частных результатах**.
Публичный `records-structures.json` содержит пустой список записей и реестр
блокеров. В Git нет исходных страниц, исторических строк или значений частной
записи. Условия TransIsrael также не являются открытой лицензией базы.

Отдельный счёт: два именованных комплекса исследованы на уровне источников —
Кармель и Хараль; одна новая частная запись утверждения об ограничении,
одно отдельное структурное наблюдение, ноль подтверждённых новых объектов.
Новизна этих комплексов относительно 965 исторических строк UNKNOWN: crosswalk
идентификаторов не получен. Ни геометрия, ни направления не достраивались по
названию, пересечению линий или соседству.

## Проверки и воспроизведение

```bash
python -m unittest tests.test_stage7_bridge_review -v
python -m scripts.stage7.bridge_review \
  --accepted-dir "$PRIVATE_STAGE5_ACCEPTED" \
  --stage6-dir "$PRIVATE_STAGE6_BRIDGES" \
  --output-dir "$PRIVATE_STAGE7_BRIDGES"
```

Девять синтетических тестов проверяют неизменность, воспроизводимость,
сохранение UNKNOWN, запрет закрытия ворот без доказательств, дубликаты,
провенанс и различение высоты опоры/проезда. Частные результаты:
`bridge-evidence-gaps.jsonl`, `manifest.json`, `summary.json`,
`records-structures.json`, `structure-observations.json`, `source-research.json`.
Все 965 продолжений воспроизводимы из сохранённых нормализованных входов;
сетевой поиск не является частью воспроизводимого преобразования.

для навигации не установлена; warning/block не внедрены.

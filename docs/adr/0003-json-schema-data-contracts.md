# ADR-0003: Контракты данных — JSON Schema 2020-12 с тестами на фикстурах в CI

- **Статус:** Принято
- **Дата:** 2026-11-14

## Контекст
Ограничения и профили ТС передаются между импортом, хранилищем, движком и клиентами. Нужен машинно проверяемый, независимый от языка контракт.

## Решение
Контракты описываются в JSON Schema draft 2020-12 (`data/*.schema.json`). В `data/examples/` хранятся валидные и заведомо невалидные фикстуры; CI проверяет их через ajv (валидные проходят, невалидные отклоняются).

## Последствия
- Изменение схемы без обновления фикстур ломает CI — это намеренно.
- Правила безопасности (например, обязательный `valueSource` для габаритов) закрепляются в схеме, а не только в коде.
- Сложные межполевые правила могут потребовать дополнительных проверок вне JSON Schema.

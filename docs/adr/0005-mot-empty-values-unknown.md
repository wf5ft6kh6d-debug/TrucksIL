# ADR-0005: Пустые значения выгрузок Минтранса (-1 / 9999 / пусто) означают «неизвестно»

- **Статус:** Принято
- **Дата:** 2026-11-14

## Контекст
В выгрузках Министерства транспорта (MoT) отсутствующие значения кодируются как `-1`, `9999` или пустая строка. Прочитанные как числа, они дают абсурдные или опасные ограничения (например, высота 9999 м — «без ограничений»).

## Решение
При импорте `-1`, `9999` и пустые значения преобразуются в «неизвестно» (null / отсутствие значения) и никогда не трактуются как число.

## Последствия
- Такие записи не могут поддерживать положительное решение (ADR-0002).
- Импортёр должен иметь тесты на каждый маркер пустого значения.
- Если появятся новые маркеры, список расширяется отдельным решением.

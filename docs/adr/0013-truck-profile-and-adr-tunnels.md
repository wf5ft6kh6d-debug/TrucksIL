# ADR-0013: Полный грузовой профиль в Valhalla и категории тоннелей ADR

- **Статус:** Принято
- **Дата:** 2026-11-21

## Контекст
`docs/research/NAVIGATORS.md`, рекомендации 1 и 2: передавать в Valhalla весь грузовой профиль и учитывать перевозку опасных грузов (ADR) через тоннели. ADR-0002: при сомнении выбираем более строгий вариант; отсутствие данных — не разрешение. ADR-0009: движок — Valhalla 3.9.

Проверено по документации Valhalla (API reference, раздел «Truck options», доступ 2026-11-21) и исходникам:
- truck costing принимает `height`, `width`, `length`, `weight`, `axle_load` (по умолчанию 9.07 т), `axle_count` (по умолчанию 5), `hazmat` (boolean), `hgv_no_access_penalty` (по умолчанию 43200 с; меньше 43200 — дороги без доступа HGV становятся разрешёнными со штрафом), `low_class_penalty`, `low_class_factor`, `use_truck_route`, а также общие для auto/truck `use_highways`, `use_tolls`, `top_speed` и др. Отдельного параметра прицепа/автопоезда нет.
- Категорий тоннелей ADR в стандартной Valhalla нет: `lua/graph.lua` сводит теги `hazmat`, `hazmat:A`…`hazmat:E` в один флаг `hazmat` («TODO: hazmat really should have subcategories»). PR с `adr_tunnel_code` (valhalla/valhalla#6244) закрыт и не влит; существует только во внешних форках. Значит, грузовик с `hazmat: true` в стандартной Valhalla объезжает любой путь с `hazmat:X=no` — это строже, чем нужно, но безопасно; тоннели без этих тегов OSM не учитываются вовсе.

## Решение
1. **Профиль → `costing_options.truck`** (`api/src/lib.js`): `heightM→height`, `widthM→width`, `lengthM→length`, `grossWeightT→weight`, `axleLoadT→axle_load`, новое необязательное `axleCount→axle_count` (целое 2–20, все оси автопоезда), `hazmat{…}→hazmat: true`. `profileName`/`note` не передаются. Поля прицепа не добавляем: Valhalla их не использует; длина/масса/оси автопоезда задаются общими полями.
2. **`hgv_no_access_penalty: 43200` передаётся всегда явно** (равно текущему значению по умолчанию), чтобы смена умолчания в будущей версии не открыла дороги без доступа грузовиков. `use_highways`, `use_tolls`, `low_class_penalty`, `use_truck_route`, `top_speed` не задаём — остаются умолчания Valhalla (это вопросы предпочтений, а не безопасности).
3. **Тоннели ADR — в нашем слое.** В `restrictions.schema.json` новый `restrictionType: "adr_tunnel"` с `unit: "adr_tunnel_category"` и строковым `value` из `B|C|D|E` (категория A = без ограничений, не хранится). В БД — колонка `value_text` (миграция `003_adr_tunnels.sql`, идемпотентная, расширяет CHECK).
4. **Код тоннеля транспортного средства:** `hazmat.adrTunnelCode` — одно из `B, B1000C, B/D, B/E, C, C5000D, C/D, C/E, D, D/E, E, -` (как в транспортном документе ADR). Из классов ADR код не выводим: он зависит от номера ООН и вида упаковки, вывести честно нельзя.
5. **Правило конфликта** (`routing.js`, `vehicleTunnelCode` / `tunnelConflict`): упрощение ADR 8.6.4 — первая буква кода есть первая запрещённая категория; проезд запрещён, если категория тоннеля ≥ этой буквы (порядок B < C < D < E). Комбинированные коды (B1000C, B/D, C5000D, D/E…) сводятся к первой букве, т.е. к самой строгой трактовке, поскольку исключения зависят от массы взрывчатки / цистерны, которые мы не моделируем. Есть `hazmat`, но нет кода → считаем код B (запрещены все категорийные тоннели). Код `-` или нет `hazmat` → тоннели не мешают. Неизвестная категория в данных → считается E. Конфликт обрабатывается как остальные: исключение и перестроение маршрута (ADR-0011).
6. **Реальные данные не выдумываем.** `data/examples/tunnels/` содержит шаблон и вымышленную запись; список израильских тоннелей там — только названия «для проверки», без категорий.

## Последствия
- Профиль полностью используется Valhalla; дороги без доступа HGV по-прежнему фактически запрещены.
- Опасные грузы проверяются строже ADR (комбинированные коды, отсутствие кода). Возможны лишние объезды — осознанный компромисс.
- Пока в БД нет ни одного реального тоннеля, проверка ничего не находит; это не означает, что тоннели на маршруте разрешены.
- Нужно: e2e-проверка на настоящей Valhalla (что `axle_count`/`hgv_no_access_penalty` принимаются без предупреждений); сбор категорий тоннелей Израиля из официальных источников; вывод `value_text` в `GET /v1/restrictions` (`api/src/app.js`).

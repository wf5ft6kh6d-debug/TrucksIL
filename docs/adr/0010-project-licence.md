# ADR-0010: Лицензия проекта

- **Статус:** Принято
- **Дата:** 2026-11-14

## Контекст
Лицензия ещё не выбрана (`README.md`). Проект использует данные OSM (ODbL) и, возможно, данные MoT (CC BY, не подтверждено, ADR-0007).

## Варианты
1. **Открытая — MIT** — простая, максимально разрешительная.
2. **Открытая — Apache-2.0** — разрешительная, с явной патентной лицензией.
3. **Проприетарная** — закрытый код, свобода монетизации.

## Замечания по ODbL
Лицензия кода не меняет условия данных. Share-alike ODbL касается производных **баз данных**: если публично использовать базу, полученную объединением OSM с другими данными, её (или способ воспроизведения) нужно предоставить на условиях ODbL. Это относится и к проприетарному варианту. «Произведённые работы» (рендер карты, маршрут) требуют атрибуции. Данные следует держать отдельно от кода и лицензировать отдельно.

## Рекомендация
Нет окончательной рекомендации: для открытого проекта предпочтительна Apache-2.0; выбор зависит от бизнес-модели владельца. Перед выбором — юридическая консультация по ODbL и лицензиям MoT.

## Решение
Код — Apache-2.0 (файлы `LICENSE`, `NOTICE`). Данные лицензируются отдельно: производные от OSM базы — ODbL; данные Минтранса — по их лицензии после письменного подтверждения (ADR-0007).

## Последствия
- Внешние вклады принимаются под Apache-2.0 (раздел 5 лицензии).
- Независимо от выбора нужен файл атрибуции данных (OSM, MoT).

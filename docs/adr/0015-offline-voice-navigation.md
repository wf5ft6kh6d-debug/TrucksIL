# ADR-0015: Офлайн-карта, голосовые подсказки и сход с маршрута в PWA

- **Статус:** Принято
- **Дата:** 2026-11-21

## Контекст
Рекомендации 4–6 из `docs/research/NAVIGATORS.md`: карта без сети (Protomaps/PMTiles), голос, контроль схода с маршрута. Клиент остаётся PWA-прототипом (ADR-0008), правило безопасности ADR-0002 не меняется: маршрут без проверки TrucksIL не показывается как действующий.

## Решение
1. **Векторная карта Израиля — PMTiles.** Сборка `planetiler` (Docker `ghcr.io/onthegomap/planetiler:0.10.2`, профиль OpenMapTiles) из уже скачанного `data/osm/israel-and-palestine-latest.osm.pbf` → `data/tiles/israel.pmtiles` (в git не попадает). nginx (сервис `web`) отдаёт `/tiles/` с Range-запросами; MapLibre читает файл через протокол `pmtiles` (npm `pmtiles` 4.5.0, точная версия). Стиль — свой минимальный (`web/src/map/style.js`) под схему OpenMapTiles, подписи `name:<язык UI>` → `name`. Глифы (Noto Sans) — самостоятельно размещённые в `data/tiles/fonts/`, без CDN. RTL (иврит/арабский) MapLibre 6 рисует без плагина (`setRTLTextPlugin` устарел), поэтому `@maplibre/maplibre-gl-rtl-text` не подключается.
   Если файла нет — растровые тайлы OSM онлайн с заметным предупреждением (только разработка; они не кешируются по политике OSM).
2. **Service worker.** Оболочка приложения — как раньше. Byte-range ответы PMTiles: network-first, копия в кеше `trucksil-tiles-v1` (LRU, 200 МБ, ключ = файл + диапазон, сброс при смене ETag). После построения маршрута клиент прогревает тайлы вдоль него (z8–14, ±1 тайл, ≤ 600 тайлов). `/api/*` **никогда** не кешируется SW.
3. **Офлайн-маршрут.** Последний успешный ответ маршрута хранится в `localStorage` устройства. Без сети он показывается только с плашкой «Офлайн: маршрут от <время>, ограничения могут быть устаревшими»; перестроение офлайн не выполняется.
4. **Голос.** Тексты манёвров — из ответа Valhalla (`verbal_transition_alert_instruction`, `verbal_pre_transition_instruction`, `verbal_post_transition_instruction`). Клиент передаёт `language` (he-IL, ru-RU, ar-SA, en-US — есть в `valhalla/locales`; иное → en-US; правка `api/src/lib.js` минимальна). Предупреждения TrucksIL (объезжаемое ограничение рядом с маршрутом впереди; мост/тоннель без данных) формируются из i18n и озвучиваются с приоритетом. Озвучка — Web Speech API; голос выбирается по языку, при отсутствии подходящего голоса — тишина и сообщение (а не чтение иврита английским голосом). Наличие голосов зависит от устройства.
5. **Навигация и сход.** `geolocation.watchPosition`; позиция привязывается к линии маршрута, вычисляются текущий манёвр и расстояние до него. Сход: дальше 50 м от линии с учётом точности (расстояние − accuracy > 50 м) дольше 10 с; фиксы с точностью хуже 100 м игнорируются. Перестроение автоматически, не чаще раза в 30 с. Режим симуляции проигрывает форму маршрута с заданной скоростью и смещением — для проверки за столом.
6. **Приватность.** Позиция не хранится и не отправляется, кроме как точка старта при запросе маршрута (включая автоматическое перестроение). Трек не записывается.

Логика — чистые модули `web/src/nav/*.js`, `web/src/map/style.js`, `web/public/sw-policy.js` с unit-тестами node:test.

## Последствия
- Карта работает без сети в просмотренных районах и вдоль построенного маршрута; остальная территория — только при наличии сети.
- Голос и переводы he/ar — машинные/движковые, нужна проверка носителями; качество ar-SA в Valhalla не проверено.
- PWA на iOS не ведёт GPS в фоне и может выгружать SW-кеш; полноценная навигация — по-прежнему в нативном клиенте (ADR-0008).
- Это не делает прототип навигатором: баннер «Не для навигации» остаётся.

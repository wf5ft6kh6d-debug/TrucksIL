# ADR-0019: TrucksIL Intelligence: исследовательский контур и граница безопасности

- **Статус:** Принято (владелец, 2026-11-24)
- **Дата:** 2026-11-24

## Контекст
Предложена подсистема TrucksIL Intelligence: автоматический сбор сведений о дорогах, проверка источников, подтверждения водителей, дорожные события и запрос альтернатив у навигационного ядра. Пилот намечен в Хайфе. Пакет требований лежит в `docs/intelligence/` (v4.0). Уже действуют ADR-0002 (отсутствие данных не разрешение), ADR-0006 и 0017 (OSM как кандидаты), ADR-0007 (лицензии), ADR-0012 (отчёты водителей отдельно от официальных данных) и ADR-0016 (цикл перестроений).

## Варианты
1. Отдельный набор из семи ИИ-агентов с правом записи в базу.
2. Модули одного сервиса в изолированном контуре без права записи в опубликованные ограничения; допуск решают детерминированные правила, модель только извлекает и предлагает.

## Рекомендация
Вариант 2. Правила:
1. Исследовательский контур пишет только в карантин доказательств. Публикация ограничений идёт через проверку и утверждение человеком, с версией снимка и откатом.
2. Всё извлечённое из внешних документов и страниц считается недоверенными данными, не командами.
3. Количество подтверждений водителей — «сила сигнала», не статус допуска и не разрешение проезда (ADR-0012). Проезд и наблюдение знака хранятся как разные типы доказательств. Значение габарита требует `valueSource: posted_sign` (ADR-0004).
4. Данные ведомств не собираются без лицензии (ADR-0007); OSM остаётся кандидатом (ADR-0006).
5. Альтернативный маршрут даёт только навигационное ядро. При UNKNOWN, незавершённом поиске или отказе ядра маршрут от модели не выдаётся.
6. Сбор данных водителей начинается только после правовой оценки по закону Израиля о защите приватности; координаты и персональные данные не уходят внешним моделям без разрешения владельца.
7. Реализация, платные запросы и развёртывание требуют отдельного решения владельца по воротам G0–G4 (`docs/intelligence/ROADMAP.md`).

## Последствия
- До принятия ADR никакой код не пишется. Первый шаг — аудит совместимости (`docs/intelligence/CODEX_TASK.md`).
- Python, Redis, внешняя ИИ-модель и VPS остаются кандидатами; каждый выбор оформляется отдельным ADR после аудита.
- Срок 12–20 недель — ориентир, не обязательство.

## Принятие
Принято владельцем 2026-11-24. Принятие разрешает только аудит совместимости (чтение, запись в `_codex_review/`). Реализация, платные запросы, развёртывание и допуск к реальной навигации требуют отдельных решений по воротам G0–G4.

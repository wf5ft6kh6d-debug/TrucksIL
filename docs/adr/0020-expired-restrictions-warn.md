# ADR-0020: Просроченные ограничения (`expired`): предупреждение и предложение маршрута в обход

- **Статус:** Принято
- **Дата:** 2026-11-24

## Контекст
ADR-0002 разрешает данным со статусом `expired` порождать только предупреждения. Фактически маршрутизация пропускала такие записи полностью и молча (`routing.js`, `restrictionsRepo.js`), поэтому ограничение, у которого истёк срок проверки, исчезало из ответа. Это обнаружил аудит совместимости (`docs/intelligence/audit/INTELLIGENCE_AUDIT.md`, п. 11).

## Решение
1. `expired` по-прежнему **не исключается** из маршрута и не запускает перестроение: решение ADR-0002 «только предупреждения» сохранено.
2. Для итогового маршрута API отдельным запросом (`findExpiredAlongRoute`) берёт `expired`-записи вдоль маршрута и, если ТС нарушило бы такую запись (с учётом направления, окон действия и совпадения по way), возвращает её в `trucksil.expiredWarnings` с причиной.
3. Если проверка не удалась или репозиторий её не поддерживает, ответ содержит `expiredCheck: "unavailable"`, а не пустой список. Пустой список при `expiredCheck: "ok"` значит только «нарушающих просроченных записей не найдено».
4. **Выбор всегда за водителем (решение владельца, 24.11.2026).** Если есть предупреждения, API дополнительно строит маршрут, который обходит и эти записи (`trucksil.alternative`, статус `alternativeStatus`: `found` / `none` / `unavailable` / `not_needed`). Основной маршрут не меняется; альтернатива только предлагается и проверяется теми же правилами. Если альтернативы нет, это сказано явно, маршрут не придумывается, а решение остаётся за водителем. Приложение само маршрут не переключает: есть кнопки «Выбрать маршрут в обход» и «Вернуться к исходному».
5. PWA показывает предупреждение отдельным блоком и сообщение «проверить не удалось»; запись не попадает в «На маршруте (проверено, конфликта нет)».
6. Покрытие мостов и тоннелей (ADR-0014) и подбор предварительных исключений не меняются: просроченная запись не считается данными.

## Последствия
- Просроченное ограничение больше не исчезает молча. Это не гарантия безопасности (ADR-0002).
- Запрос альтернативы удваивает работу API на маршрутах с предупреждением. В ответе у альтернативы нет данных покрытия мостов, отчётов водителей и скоростей: клиент честно показывает «не определено».
- Тот же принцип (предупредить, предложить обход, решение за водителем) применим к перекрытиям и другим препятствиям; их ввод относится к этапу 5 (события) и к ADR-0019.
- Автоперевод в `expired` по `review_due_at` по-прежнему не реализован (задача DATA-3 аудита).
- Тексты `restr.expired` на иврите и арабском машинные, нужна проверка носителем.

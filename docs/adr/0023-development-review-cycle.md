# ADR-0023: Цикл разработки с независимой проверкой и утверждением владельца

- **Статус:** Принято (владелец, 2026-11-24)
- **Дата:** 2026-11-24

## Контекст
Ошибка маршрута для грузовика может привести к аварии (ADR-0002). Часть работы выполняют ИИ-агенты, и ни один агент не должен утверждать собственную работу. Схема применяется ко всему проекту, включая TrucksIL Intelligence (ADR-0019). До этого решения аудит совместимости (PR #21) выполнил подагент той же сессии, что и разработка, а PR #19–#26 влиты без проверки Codex.

## Решение
Работа идёт по циклу:
1. **Задание** формулирует владелец (или утверждает формулировку).
2. **Claude Code** выполняет работу в отдельной ветке и открывает черновик пулреквеста: код, тесты, документы, ссылки на ADR.
3. **Codex** независимо проверяет результат: корректность, безопасность (ADR-0002, ADR-0012), соответствие ADR и тестам. Проверяющий не должен быть автором и не получает заключение автора как готовый вывод.
4. **Анализ результатов:** найденные замечания разбираются; отклонить замечание можно только с причиной, понятной владельцу.
5. **Исправления** вносит Claude Code в ту же ветку.
6. **Повторный аудит** Codex после исправлений. Цикл повторяется, пока нет открытых критичных замечаний.
7. **Утверждение владельцем.** Слияние (merge) выполняется только после явного слова владельца. Его не заменяют зелёный CI, отчёт агента или результат проверки Codex.
8. **Merge** в `main` после утверждения.

Правила:
- Ни один агент не утверждает собственную работу: не ставит PASS без запуска проверки, не отмечает этап завершённым по своему отчёту, не вливает PR сам.
- Статусы проверок только PASS, FAIL, BLOCKED, NOT_RUN. Непроверенное остаётся NOT_RUN и не пишется как «работает».
- Изменения, затрагивающие безопасность маршрутизации, ограничения, приватность и данные водителей, требуют шага Codex обязательно. Документы без влияния на поведение (например инструкции) могут идти по сокращённому пути: утверждение владельца и зелёный CI, с пометкой в PR.
- Окружение, которого агент не может проверить (настоящая PostGIS, Valhalla, браузер, устройство), проверяет владелец по `docs/LOCAL_TEST_GUIDE.md`; результат записывается в PR или в `docs/DEV_SETUP.md`.
- Публичный запуск разрешается только по ADR-0022 (п. 6) после прохождения цикла и письменного решения владельца.

## Последствия
- Слияние замедляется, зато каждое изменение проходит независимый взгляд.
- Ретроспективный аудит Codex для уже влитых PR #19–#26 назначается владельцем; особенно важен код (PR #22, #23).
- Если Codex недоступен, изменение остаётся в черновике: подагента той же сессии нельзя считать независимой проверкой.
- Для TrucksIL Intelligence (ADR-0019) каждый этап и каждый ADR-предложенный (A1–A14) проходит этот цикл до реализации.

# ADR-0008: Платформа MVP

- **Статус:** Предложено (решение за владельцем проекта)
- **Дата:** 2026-11-14

## Контекст
Водителям нужен мобильный клиент: многоязычный интерфейс (иврит/RTL, арабский, русский, английский), профили ТС, офлайн-режим и состояния отказа (`docs/PRODUCT_REQUIREMENTS.md`). Маршрутизация не включается до прохождения проверок безопасности, поэтому первые версии — прототипы.

## Варианты
1. **PWA** — быстрый старт, один код, без магазинов; ограничения фоновой навигации, GPS в фоне и офлайна на iOS.
2. **React Native** — нативные приложения, зрелые библиотеки карт (MapLibre), общий стек с веб (TypeScript).
3. **Flutter** — высокая производительность UI, хорошая поддержка RTL; отдельный язык (Dart), меньше переиспользования с вебом.

## Рекомендация
Сначала PWA-прототип для проверки UX, профилей и отображения предупреждений; для навигации в реальных поездках — переход на React Native или Flutter (выбор после прототипа).

## Последствия
- Прототип дёшев, но не годится для пошаговой навигации.
- Бизнес-логику и контракты (ADR-0003) держать вне UI, чтобы переход был дешёвым.

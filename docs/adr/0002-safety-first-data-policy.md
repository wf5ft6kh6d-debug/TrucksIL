# ADR-0002: Безопасность прежде всего — отсутствие данных не означает разрешения

- **Статус:** Принято
- **Дата:** 2026-11-14

## Контекст
Ошибка маршрута для грузовика (мост ниже высоты ТС, запрет по массе) может привести к аварии. Покрытие ограничений в открытых данных неполное (см. `docs/OSM_COVERAGE.md`), официальные источники ещё не подтверждены (`docs/DATA_SOURCES.md`).

## Решение
- Отсутствие сведений об ограничении **не** является доказательством проходимости дороги; неизвестное покрытие показывается водителю.
- Данные со статусом, отличным от `verified` (`unverified`, `disputed`, `expired`), могут порождать только **предупреждения**.
- Положительное решение о пригодности маршрута опирается только на данные со статусом `verified` и не истёкшим сроком проверки (см. `docs/DATA_VERIFICATION.md`).

## Последствия
- Маршрутов с полной гарантией на старте будет мало; интерфейс обязан честно показывать ограничения.
- Требуется хранить статус, дату проверки и срок пересмотра для каждого ограничения.
- Тесты должны проверять, что непроверенные данные никогда не дают «зелёный» результат.

## Дальнейшие шаги
- Покрытие маршрута «без данных» для мостов и тоннелей — [ADR-0014](0014-route-coverage.md).

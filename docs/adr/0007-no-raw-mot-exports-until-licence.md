# ADR-0007: Сырые выгрузки Минтранса не коммитятся до письменного подтверждения лицензии

- **Статус:** Принято
- **Дата:** 2026-11-14

## Контекст
Данные MoT, вероятно, публикуются по лицензии CC BY, но конкретная версия и условия для этих наборов не подтверждены (`docs/DATA_SOURCES.md`). Публикация чужих данных в репозитории без ясной лицензии — юридический риск.

## Решение
Сырые выгрузки MoT не добавляются в репозиторий, пока лицензия (включая версию CC BY) не подтверждена письменно правообладателем. До этого разрешены только скрипты, схемы и синтетические фикстуры.

## Последствия
- Разработчики загружают данные локально; воспроизводимость обеспечивается скриптами.
- После подтверждения лицензии решение пересматривается новым ADR с текстом атрибуции.

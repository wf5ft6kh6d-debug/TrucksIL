# ADR-0018: Таймер смены в PWA (US-06)

- **Статус:** Принято
- **Дата:** 2026-11-21

## Контекст
US-06 (`docs/PRODUCT_REQUIREMENTS.md`): водитель отмечает начало смены, перерывы и конец и получает предупреждения до своего лимита. Это **напоминание, а не юридическое подтверждение** соблюдения режима труда и отдыха: правила зависят от категории водителя и работодателя, а продукт не сертифицирован как тахограф. Клиент — PWA-прототип (ADR-0008), должен работать офлайн; правило безопасности ADR-0002 не затрагивается. Голос — общая очередь ADR-0015.

## Решение
1. **Чистый модуль `web/src/shift/timer.js`.** Конечный автомат `idle → driving ⇄ break → ended` (действия start/break/resume/end, недопустимые переходы игнорируются). Состояние — список событий с метками `Date.now()`; все суммы (вождение, перерывы, длительность смены, текущее непрерывное вождение) вычисляются из разностей меток, а не из счёта тиков, поэтому усыплённая вкладка или перезагрузка ничего не теряют. Часы, ушедшие назад, не дают отрицательных интервалов.
2. **Лимиты настраиваются пользователем.** По умолчанию: смена 12 ч, вождение 9 ч, напоминание о перерыве после 4,5 ч непрерывного вождения (можно отключить). В UI подписаны как собственные настройки напоминаний, не как норма закона.
3. **Напоминания** за 2 ч, 1 ч, 30 мин до каждого лимита и в момент лимита. Каждое срабатывает один раз за смену (идентификаторы сработавших хранятся в состоянии); напоминание о непрерывном вождении заново взводится в каждом отрезке вождения после перерыва. Пороги не короче самого лимита пропускаются. Если вкладка спала и пройдено несколько порогов — показывается только самый срочный. Лимит вождения и непрерывного вождения на перерыве не идёт.
4. **Каналы:** всегда видимое сообщение (`role=alert`); голос через очередь `nav/speech.js` с высоким приоритетом — только если голос включён пользователем и есть голос для языка (иначе тишина, как в ADR-0015); системное уведомление (Notification API) — только если разрешение уже выдано; разрешение запрашивается только по нажатию кнопки.
5. **Приватность.** Текущая смена, настройки и история последних 7 смен — только в `localStorage` устройства (`trucksil.shift.*.v1`); в API ничего не отправляется. Экспорт CSV формируется в браузере (UTC, минуты). Есть кнопка очистки истории.
6. Постоянная плашка «Напоминание, не юридическое подтверждение соблюдения режима труда и отдыха» на 4 языках; he/ar — машинный перевод, нужна проверка носителем.

## Последствия
- Работает офлайн и переживает перезагрузку; тесты node:test с поддельными часами, smoke с `page.clock` Playwright.
- В фоне PWA (особенно iOS) таймеры JS останавливаются: суммы при возврате верны, но напоминание прозвучит только когда приложение снова активно. Надёжные фоновые напоминания — задача нативного клиента.
- Не тахограф и не доказательство для проверок; формулировки не должны обещать соответствие закону.

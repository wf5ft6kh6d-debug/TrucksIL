# ADR-0022: Только бесплатные уровни, пока нет протестированного прототипа

- **Статус:** Принято (владелец, 2026-11-24)
- **Дата:** 2026-11-24

## Контекст
Для Intelligence (ADR-0019) и пилота нужны платные службы: сервер, Firecrawl, модели OpenAI, дорожные данные TomTom и HERE, запрос по закону о свободе информации, юрист. Обзор цен: см. таблицу в `docs/legal/LICENCE_DECISIONS.md` и расчёт от 24.11.2026 (Firecrawl Hobby $19/мес, VPS $13–26/мес, речь OpenAI $0,003–0,006 за минуту, пошлина за запрос 24 ₪ и далее до обязательства в 180 ₪; цены на момент обзора, часть не проверена). Владелец решил: платить только после того, как прототип готов и протестирован.

## Решение
1. **До готового протестированного прототипа ничего платного не подключаем:** ни платные планы Firecrawl, ни API OpenAI, ни платные данные (HERE, TomTom сверх бесплатного уровня, MAPI), ни аренда сервера, ни юрист, ни оплаченный запрос по закону о свободе информации.
2. **Что используем:** OSM, Valhalla, PostGIS и PWA на своём компьютере владельца (Docker, WSL); бесплатный уровень Firecrawl (1 000 кредитов в месяц) только для документов из реестра разрешённых источников; бесплатные уровни провайдеров по их официальным условиям.
3. **Лимит расходов: 0.** Любая служба, которая может списать деньги (карта, автопродление, превышение лимита), не подключается без отдельного письменного слова владельца. Если бесплатный лимит исчерпан, сбор останавливается и пробел фиксируется (ADR-0019, SAFETY_PROTOCOL).
4. **Отложено до решения владельца после тестирования прототипа:** запрос по закону о свободе информации (пошлина), правовая оценка приватности (`docs/legal/PRIVACY_BRIEF.md`), аренда сервера, платные данные. Это не отменяет блокировки: сбор данных водителей в пилоте остаётся невозможным без правовой оценки.
5. **Не зависит от денег и продолжается:** письма в Аялон и Waze через веб-формы (бесплатно), ожидание ответа Нетивей Исраэль (напоминание 05.12.2026), документация и тесты.

## Последствия
- Прототип проверяется локально: нельзя дать водителям доступ из интернета, пока нет сервера.
- Если Нетивей Исраэль не ответит бесплатным путём, получить данные можно только после оплаты: это потребует нового решения владельца.
- Цены меняются: перед включением любой платной службы цены проверяются заново.

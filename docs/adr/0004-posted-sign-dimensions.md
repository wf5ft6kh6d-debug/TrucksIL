# ADR-0004: Водителю показывается значение со знака; измеренный габарит хранится отдельно

- **Статус:** Принято
- **Дата:** 2026-11-14

## Контекст
Для ограничений по высоте/ширине/длине существуют значение на дорожном знаке и фактически измеренный габарит (часто больше). Водитель и закон ориентируются на знак; подмена знака измерением может ввести в заблуждение и создать юридический риск.

## Решение
- Значение ограничения по высоте, ширине и длине, показываемое водителю и используемое для решений, — значение со знака: `valueSource = posted_sign`, обязательно для габаритных ограничений.
- Измеренный габарит (`measured`) хранится в отдельном поле и никогда не подставляется вместо значения знака.

## Последствия
- Схема ограничений требует `valueSource=posted_sign` для габаритов; иные источники значения не проходят валидацию.
- Если знак неизвестен, ограничение не может поддержать положительное решение (см. ADR-0002).
- Измерения остаются полезны для проверки и выявления расхождений.

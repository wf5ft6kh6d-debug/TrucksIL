# ADR-0001: Фиксировать архитектурные решения в виде ADR

- **Статус:** Принято
- **Дата:** 2026-11-14

## Контекст
Проект TrucksIL связан с безопасностью движения и лицензиями на данные. Решения принимаются несколькими людьми и агентами; без записи их причины теряются, а решения пересматриваются повторно.

## Решение
Каждое значимое архитектурное решение оформляется как ADR в `docs/adr/` по формату Майкла Найгарда (Статус / Контекст / Решение / Последствия), на русском языке. Файлы нумеруются `NNNN-краткое-имя.md`, индекс ведётся в `docs/adr/README.md`. Принятые ADR не переписываются: изменение оформляется новым ADR со статусом «Заменяет ADR-NNNN».

## Последствия
- Причины решений доступны новым участникам и ревьюерам безопасности.
- Небольшие дополнительные затраты на оформление.
- Решения со статусом «Предложено» явно показывают, что ждёт выбора владельца.

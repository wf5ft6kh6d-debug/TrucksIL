# Этап 6: пробелы доказательств мостовых записей

Использованы **965 ранее принятых нормализованных строк** этапа 5.
XLSX повторно не импортировался и не запрашивался. Приватный реестр связывает
каждую запись с исходным SHA, XML member, листом, строкой и ID этапа 5.
Принятые входы проверяются по числу строк, согласованности SHA и составу ID;
дубликаты/повышенные статусы отвергаются. Исходники не меняются.

сохранено в свидетельствах этапа 5; оно не выполнялось повторно и не доказывает
действующий габарит. Даты создания/изменения файла 2017 года не являются
датами измерения. Единицы высот по-прежнему UNKNOWN.

## Приоритет независимой проверки

| Очередь | Основание | Строк |
|---|---|---:|
| 1 | Одновременно есть знак и хотя бы один физический просвет: сначала установить их смысл и применимость | 327 |
| 2 | Есть знак, отсутствуют оба поля физического просвета | 8 |
| 3 | Есть просвет, нет значения знака | 430 |
| 4 | Только высота опоры, не габарит проезда | 136 |
| 5 | Нет ни одного высотного наблюдения | 64 |

Это порядок аналитической работы, **не оценка риска и не разрешение проезда**.
Внутри очереди порядок определяется SHA, XML member, номером строки и ID.
Никакой сортировки по предполагаемой высоте в метрах, сравнения с грузовиком
или вывода о конфликте чисел до проверки единиц и семантики нет. Разница
значений знака и физического просвета сама по себе не доказывает ошибку.

Для всех 965 строк открыты десять ворот: официальный источник; права повторного
использования; словарь полей/единиц; дата/метод измерения; действующее официальное
свидетельство; идентичность сооружения и роль дороги; геометрия подмостового
проезда; направление/полоса; соотношение знака и физического просвета;
независимая проверка. Дополнительно: 208 строк без физического просвета,
630 без значения знака. Высота опоры эти пробелы не закрывает.

Следующий конкретный шаг: получить от ответственного оператора документированный
словарь четырёх высотных полей, единиц и направлений, официальный crosswalk
идентификаторов сооружения/дороги под ним, датированные измерения и условия
повторного использования. Для очереди 1 сначала проверять существование объекта,
актуальность и принадлежность знака конкретной полосе; потом сравнивать числа.
Письма, заявки, платные обращения не отправлялись. Общие страницы и поисковые
результаты не используются как автоматически проверенные ограничения.

## Код, тесты и воспроизведение

`scripts/stage6/bridge_gaps.py`: `build_gap(record)`, `build_registry(records)`
и `process_accepted(records_path, manifest_path, summary_path, output_dir)`.
Публичный код не содержит реальных строк или высот. CI использует только
синтетические фикстуры. Локально **11/11 профильных тестов PASS**: все ворота,
честный охват, порядок очереди, опора/просвет, дубликаты, запрет повышения,
неизвестные поля, неразобранные числа, стабильность/неизменность, provenance,
ошибка количества строк и запрет перезаписи входов.

```bash
python -m unittest tests.test_stage6_bridge_gaps -v
python -m scripts.stage6.bridge_gaps --accepted-dir "$PRIVATE_ACCEPTED_DIR" --output-dir "$PRIVATE_STAGE6_DIR"
```

Приватные результаты: `bridge-evidence-gaps.jsonl`, `summary.json`, `manifest.json`;
отдельно сохранён `source-research.json` с URL, областью исследования и статусом
доступа. В manifest — SHA-256 всех трёх принятых входов. Реестр и исходники
не включаются в Git и публичные CI artifacts. Общая интеграция и национальный
CI находятся в ответственности интегратора; этот отчёт не объявляет их PASS.

# Чек-лист закрытой проверки владельцем

Проверку делает только владелец на своём компьютере. Публичного доступа нет, прототип водителям не показывается, пока владелец не подтвердит результат письменно (ADR-0022, п. 6). Подробности запуска: `docs/DEV_SETUP.md`. Отмечайте результат: PASS, FAIL или NOT_RUN.

## 0. Подготовка
```bash
cd ~/TrucksIL && git pull
npm ci && npm test
docker compose --profile routing up -d --build
```
Если том базы создан давно, применить недостающие миграции (см. `docs/DEV_SETUP.md`, разделы про миграции 002–005). `docker compose down -v` стирает все данные базы.

## 1. Автоматические проверки
- [ ] `npm test`: все тесты проходят
- [ ] `npm run test:py`
- [ ] `npm run test:e2e`: нет FAIL (SKIP для S10 и S12e допустим)
- [ ] `(cd web && npm run build) && npm run test:web-smoke`

## 2. Просроченное ограничение и объезд (ADR-0020)
1. Добавить вымышленное ограничение по инструкции «Ручная проверка объезда» в `docs/DEV_SETUP.md` (скрипт `scripts/dev_add_test_restriction.js`).
2. Сделать его просроченным:
   ```bash
   docker compose exec db psql -U trucksil -d trucksil -c "UPDATE restrictions SET status='expired' WHERE id='dev-test-max-height';"
   ```
3. Запросить маршрут для машины выше ограничения. Ожидается: основной маршрут не меняется, в `trucksil.expiredWarnings` есть запись, `alternativeStatus` равен `found` или `none`.
4. В приложении: появился блок предупреждения; кнопка «Выбрать маршрут в обход» меняет маршрут только по нажатию, «Вернуться к исходному» возвращает его.
5. Удалить запись: `node scripts/dev_add_test_restriction.js delete`.
- [ ] Предупреждение видно, маршрут сам не переключается

## 3. Просроченная проверка (ADR-0021)
1. Выставить вымышленной записи `status='verified'`, `verified_by='test'`, `verified_at=now()`, `review_due_at` в прошлом.
2. Запросить маршрут: запись должна идти как `unverified` и по-прежнему избегаться.
3. Пробный запуск: `node scripts/demote_overdue_reviews.js` (только список), затем `--apply`; в таблице `restriction_events` должна появиться запись с актором `system:review-due`.
- [ ] Запись не считается проверенной, объезд сохраняется

## 6. Решение о публикации
Публиковать прототип можно только после того, как владелец сам прошёл этот чек-лист, записал результаты и дал письменное разрешение. До этого: никакого публичного адреса, сервера в интернете и приглашений водителям.

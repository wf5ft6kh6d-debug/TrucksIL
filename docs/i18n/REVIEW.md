# Ревизия переводов веб-клиента (he / ar)

Строки интерфейса находятся в `web/src/i18n.js`. Переводы на иврит и арабский — **машинные** и требуют проверки носителем языка. ru/en — исходные. Этот документ — инструкция и сводная таблица; рабочий файл для заполнения — `docs/i18n/strings.csv`.

## Как проводить ревизию

1. Откройте `docs/i18n/strings.csv` в Excel / LibreOffice / Google Sheets (UTF-8 с BOM — иврит и арабский отображаются корректно).
2. Для каждой строки сравните `he_current` / `ar_current` с `en` и `ru`. Колонки `*_suggested` — предложения разработчика (только там, где мы достаточно уверены), `notes` — на что обратить внимание.
3. Окончательный текст впишите в `he_reviewed` / `ar_reviewed`. Пустая ячейка = «оставить как есть». Если согласны с предложением — скопируйте его в `*_reviewed`.
4. Сохраните как CSV (UTF-8) и примените:
   ```
   node scripts/i18n_apply_review.js docs/i18n/strings.csv --dry-run   # показать изменения
   node scripts/i18n_apply_review.js docs/i18n/strings.csv             # записать в web/src/i18n.js
   ```
   Скрипт откажется применять строку, если в ней потеряны/изменены плейсхолдеры.

## Правила

- **Плейсхолдеры** `{km}`, `{min}`, `{reroutes}`, `{verified}`, `{unverified}`, `{status}` оставлять дословно (латиницей, в фигурных скобках). Порядок в предложении можно менять.
- **Тексты безопасности** (`banner.*`, `err.*`, `type.*`, `status.*`) должны оставаться однозначными; не сокращать. «Маршрут не показан» должно явно означать, что маршрута нет.
- **«posted sign»** (`source.posted_sign`) — значение ограничения взято с установленного дорожного знака. Используйте официальный термин (HE: תמרור; AR: شاخصة/إشارة مرورية), не общее «знак/символ».
- **«unverified»** — «не проверено/не подтверждено данными», а не «недостоверно» или «сомнительно».
- **«prototype»** — приложение экспериментальное, не для навигации.
- **RTL**: следите за пунктуацией и смешением с латиницей/цифрами (`API`, `ADR`, `TrucksIL`, `34.78,32.08`, `≠`). Числа — западные арабские цифры (0–9), десятичная точка.
- **Единицы**: м, т, км, мин — сокращения, принятые в языке (HE: מ׳, טון, ק״מ, דק׳ — с гершем ׳/гершаим ״, не апострофом/кавычкой).
- **Род и число**: «ограничения» в иврите ж.р. мн.ч. (הגבלות) — прилагательные согласовать.

## Иврит: «אב-טיפוס» (banner.prototype)

Текущее: `אב-טיפוס. לא לניווט.` Проблемы: (1) нормативное написание — `אב טיפוס` (раздельно) или с макафом `אב־טיפוס`; ASCII-дефис `-` — нейтральный bidi-символ и в некоторых шрифтах/контекстах отображается неправильно; (2) «לא לניווט» слишком телеграфно для предупреждения. Предложение: `אב טיפוס. אין להשתמש לניווט.` — требует подтверждения носителем.
